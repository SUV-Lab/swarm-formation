## 4. 회수한 식 — 본문 (1)–(18)

### 4-1. 각도·마하 (식 1–3, 3쪽)

```
α_tot = cos⁻¹( V_Rx / V_R )                     (1)   범위 0°~+180°, 음수 없음
φ_A   = tan⁻¹( V_Ry / V_Rz )                    (2)   범위 −180°~+180°
MACH  = V_R / V_sound                           (3)
```

`V_Rx, V_Ry, V_Rz` 는 **B 프레임의 V⃗_R 성분을 MRP 로 옮긴 것**.

### 4-2. 정적 계수 6개 (2–3쪽)

```
C_Am    축력      C_Ym    측력      C_Nm    법선력
C_lm    롤 모멘트  C_mm    피치 모멘트  C_yawm  요 모멘트
```

**부호 규약**: `C_Am`, `C_Nm` 은 각각 **X축·Z축의 반대 방향이 양**.
모멘트 셋은 **오른손 법칙**으로 양.

**축대칭 단순화 (원문 명시)**: 중심선 축대칭이면 M 프레임의 X-Z 평면이
V⃗_R 을 포함하는 대칭면이므로 **정적 횡방향 계수 3개(`C_Ym`, `C_lm`,
`C_yawm`)를 0 으로 둘 수 있다.**

**범위 주의**: 0 이 되는 것은 **정적** 계수 셋뿐이다. 각속도가 만드는
롤·요 **감쇠**(`C_lmd`, `C_yawmd`, 식 7·9)는 제거되지 않는다. 1회차가
"남는 것은 셋"이라 적은 것은 정적 계수에 한정해야 한다.

의존 변수: 일반적으로 (α_tot, φ_A, Mach). **축대칭이면 (α_tot, Mach) 뿐**
— φ_A 에 무관.

### 4-3. 감쇠 미계수 (식 4–6, 5쪽)

```
C_lpm   = ∂C_lm   / ∂( p_m · D_ref / (2 V_R) )      (4)
C_mqm   = ∂C_mm   / ∂( q_m · D_ref / (2 V_R) )      (5)
C_yawrm = ∂C_yawm / ∂( r_m · D_ref / (2 V_R) )      (6)
```

무차원화 인자는 **`D_ref / (2 V_R)`** — 항공기 관례의 `b/(2V)`, `c̄/(2V)`
와 달리 **세 축 모두 `D_ref`** 를 쓴다.

**적용 지점 규약** (5쪽, 중요):
- 감쇠 미계수는 **MRP 가 아니라 무게중심(에 가까운 곳)** 에서 개발한다
- 좌표계는 **M 프레임에 평행**하고 원점은 중심선 위 무게중심의 X 위치
- 개발 후 **MRP 에서 M 프레임으로 적용**한다 (순수 우력이므로 어느 점에나 적용 가능)
- 중심선에서의 작은 횡방향 무게중심 편차는 무시

각속도 `p_m, q_m, r_m` 은 **B 프레임 몸체 각속도를 중심선 둘레로
`−φ_A` 회전**시켜 얻는다.

### 4-4. 감쇠 모멘트 계수 (식 7–9, 6쪽)

계수와 각속도의 **선형 관계 가정**:

```
C_lmd   = ( p_m · D_ref / (2 V_R) ) · C_lpm         (7)
C_mmd   = ( q_m · D_ref / (2 V_R) ) · C_mqm         (8)
C_yawmd = ( r_m · D_ref / (2 V_R) ) · C_yawrm       (9)
```

### 4-5. M 프레임 힘·모멘트 (식 10–11, 7쪽)

```
F⃗_m = Q · S_ref · [ −C_Am , C_Ym , −C_Nm ]ᵀ                        (10)

M⃗_m = Q · S_ref · D_ref · [ C_lm + C_lmd ,
                             C_mm + C_mmd ,
                             C_yawm + C_yawmd ]ᵀ                    (11)
```

식 (10) 의 **1·3 성분에 음부호**가 붙는 것이 §4-2 의 부호 규약과 맞물린다.
모멘트는 `S_ref · D_ref` 로 차원화한다 — 세 축 공통.

### 4-6. M → P 변환 (식 12–13, 7쪽)

중심선 둘레로 공력 롤각 `φ_A` 회전:

```
        ⎡ 1     0        0    ⎤
R_pm =  ⎢ 0   cos φ_A  sin φ_A ⎥        F⃗_p = R_pm F⃗_m   (12)
        ⎣ 0  −sin φ_A  cos φ_A ⎦        M⃗_p = R_pm M⃗_m   (13)
```

### 4-7. P → B 변환 (식 14–18, 7–8쪽)

```
F⃗_b = F⃗_p                                                          (14)
M⃗_b = M⃗_p + MRP⃗_b × F⃗_p                                           (15)

M_Xb = M_Xp + MRP_Yb·F_Zp − MRP_Zb·F_Yp                             (16)
M_Yb = M_Yp + MRP_Zb·F_Xp − MRP_Xb·F_Zp                             (17)
M_Zb = M_Zp + MRP_Xb·F_Yp − MRP_Yb·F_Xp                             (18)
```

`MRP⃗_b` 는 **무게중심 기준 MRP 위치**(B 프레임).

### 4-8. 식 (2) 의 구현 계약 — `atan2` 와 끝점 규약

원문 식 (2) 는 `tan⁻¹(V_Ry/V_Rz)` 로 적혀 있으나 **범위가 −180°~+180°**
이므로 구현은 **`atan2(V_Ry, V_Rz)`** 여야 한다. 단순 `atan(y/z)` 는
−90°~+90° 만 낸다.

그리고 원문이 직접 못 박는 것을 1회차가 놓쳤다 (3쪽):

> *"It is imperative to note that **singularities exist in the φ_A equation
> at α_tot = 0° and 180°**, and these must be handled by **specifying a value
> of φ_A (such as 0°)** for these two values of α_tot."*

끝점에서 V⃗_R 이 X 축과 평행해 `V_Ry = V_Rz = 0` 이 되므로 φ_A 가 정의되지
않는다. **명시적 규약이 필수**이고 원문은 0° 를 예로 든다.

## 4-9. 부록 — 1회차가 통째로 빠뜨린 것

1회차는 "식 (1)–(18) 전부"라고 적었으나 **본문만 다뤘다.** 원문에는
부록 A.1–A.12, B.1–B.6 이 더 있고, **단순 설명이 아니라 사용 가능한
해석식을 포함한다.**

### A — 감쇠 미계수의 등가 (제한된 예제)

```
C_mmd = −( q_m · D_ref / (2 V_R) ) · C_fin                          (A.9)
C_mmd = (∂C_mm / ∂q_m) · q_m                                        (A.10)
C_fin = −∂C_mm / ∂( q_m D_ref / (2 V_R) )                           (A.11)
C_mqm =  ∂C_mm / ∂( q_m D_ref / (2 V_R) )                           (A.12)
```

(A.11) 과 (A.12) 의 우변이 부호만 다르므로:

> **`C_mqm = −C_fin`** — 피치 감쇠 미계수는 수평 미익의 법선력 계수의
> 음수와 같다.

**전제**: 부록 A 가 세운 **단순 예제**(수평 미익 하나)에 한한다. 일반
형상으로 확장되지 않는다.

### B — 교차류 원통의 피치 감쇠 모멘트 (해석식)

```
M_di = −ρ V_R q_m C X² D dx                                          (B.5)

M_d  = −(1/3) ρ V_R q_m C D L³ (1 − 3·cg + 3·cg²)                    (B.6)
```

`cg` 는 무차원 무게중심 위치, `L` 은 원통 길이, `C` 는 교차류 계수,
`D` 는 직경. 원문이 밝히듯 **피치 감쇠가 무게중심 위치와 원통 길이에
크게 민감**하다는 것을 보인다.

**전제**: 교차류 조건의 원통(미익·노즈콘 제외), 정적 항 제외.

### 5-1. 가장 중요한 공백

> **원문은 계수의 *구조·프레임·차원화·적용 순서* 를 준다. 일반 계수 *값*
> 은 주지 않는다. 다만 제한된 형상·가정 아래 해석식 일부는 제공한다.**

`C_Am`, `C_Nm`, `C_mm` 을 α_tot × Mach 격자에 채우는 것은 별도 자료가
필요하다. 감쇠 쪽은 1회차가 "전부 외부 자료 필요"라 적었으나 **너무 넓다**
— 부록 A·B 가 제한된 조건의 해석식을 준다(§4-9).

**이것은 "회수 실패"가 아니다.** 회수한 것은 **틀 전체**이고, 그 틀이
요구하는 입력 목록이 위 표다. 자체 추정으로 계수를 만들더라도 **이 틀에
꽂아 넣으면 프레임·부호·차원화를 스스로 정하지 않아도 된다** — 그것이
이 회수의 값이다.

## 6. 저동압·저속·큰 받음각 적용성 — 별도 판정

| 영역 | 판정 | 근거 |
|---|---|---|
| 큰 받음각 (0°~180°) | **기구학적 표현만 보장** | 식 (1) 이 그 범위를 표현하도록 정의된다. **계수의 물리적 유효범위는 원문이 주지 않는다** |
| α_tot = 0° / 180° 끝점 | **명시 규약 필요** | φ_A 가 정의되지 않는다. 원문이 0° 같은 값을 지정하라고 못 박음(§4-8) |
| 롤 자세 전 범위 | 기구학적 표현만 보장 | M 프레임이 V⃗_R 을 X-Z 평면에 고정 |
| **저속·저동압** | **원문이 판정하지 않는다** | §6-1 |

### 6-1. 저동압에서 무엇이 무너지는가 — 형식적 검토

원문은 속도 하한을 논하지 않는다. 식에서 직접 보이는 것:

1. **식 (1) `α_tot = cos⁻¹(V_Rx / V_R)`** — `V_R → 0` 에서 정의되지 않는다.
   0으로 나누기.
2. **식 (4)–(9) 의 `D_ref / (2 V_R)`** — `V_R → 0` 에서 발산한다. 감쇠
   모멘트 계수가 무한대로 간다.
3. **식 (10)–(11) 의 `Q`** — `Q → 0` 이므로 힘·모멘트는 0 으로 간다.

2와 3이 상쇄되는지는 **곱을 보면 유한**하다:

```
M ∝ Q · S_ref · D_ref · (q_m D_ref / (2 V_R)) · C_mqm
  ∝ (½ ρ V_R²) · (q_m / V_R)
  ∝ ρ V_R q_m          →  V_R → 0 에서 0
```

즉 감쇠 모멘트 자체는 유한하고 0 으로 간다. **발산하는 것은 무차원 계수
`C_mmd` 이지 모멘트가 아니다.** 다만 구현이 계수 단계에서 클램프하면
그 클램프가 물리를 바꾼다.

**전제를 명시한다** — 이 상쇄 논증은 `ρ`, `q_m`, `C_mqm` 이 저속에서
**유한**하다는 가정 위에서만 성립한다. 정적 힘도 마찬가지로 `C_Am`,
`C_Nm` 이 저속·저 Mach 에서 유한해야 `Q → 0` 이 힘을 0 으로 보낸다.
**원문에 계수값이 없으므로 이 유한성은 확인되지 않았다.**

**식 (1) 은 상쇄되지 않는다** — `V_R → 0` 에서 α_tot 자체가 정의되지
않으므로 정적 계수를 조회할 인자가 없다.

### 6-2. 판정

> **저동압·저속 영역의 적용성은 원문으로 판정할 수 없다.** 문서는 상승과
> 재진입을 대상으로 하며 속도 하한을 명시하지 않는다. 식 수준에서는
> 감쇠 모멘트가 유한하게 0 으로 가지만, **α_tot 정의가 V_R → 0 에서
> 무너지므로 정적 계수 경로에 하한이 필요하다.** 그 하한값은 원문이
> 주지 않는다.

초기 수직 구간의 시작 속도가 0 이 아님(ADR-0003 §2 경우 B)은 이 문제를
**완화하지만 제거하지는 않는다** — 하한을 얼마로 둘지는 여전히 결정 사항이다.

## 부록 A — 영상 판독 결과 (1회차 미포함분)

```
Q_fin = ½ρ(V_R² + 2V_R D_ref q_m + D_ref² q_m²)                     (A.1)
Q_fin = ½ρ(V_R² + 2V_R D_ref q_m)          ← 3항 무시              (A.2)
F_fin = Q_fin C_fin S_fin                                            (A.3)

C_mmd = (∂C_mm/∂q_m) · q_m                                          (A.10)
C_fin = −∂C_mm / ∂(q_m D_ref / 2V_R)                                (A.11)

### A 의 전제 — 1회차는 "수평 미익 하나"로만 적었다. 여섯 개다

원문이 명시하는 전제 전부:

1. **후미 수평 미익 하나가 피치 감쇠 전부를 담당** (*"not necessarily

**전제** (1회차는 셋만 적었다):

1. **교차류 조건**의 원통 — 미익·노즈콘 제외

### B.6 은 `C_mqm` 을 직접 주지 않는다

1회차 표가 *"(B.6) 이 `C_mqm` 값을 직접 준다"* 는 식으로 읽히게 적었다.
**틀렸다** — B.6 은 **`M_d` (모멘트)** 다. `C_mqm` 으로 가려면 A.8 과
식 (8) 을 거쳐야 한다:

```

(8):   C_mmd = (q_m D_ref / 2V_R) C_mqm
  ⇒    C_mqm = 4 M_d / (ρ V_R q_m S_ref D_ref²)

B.6 대입 ⇒  C_mqm = −(4/3) C D L³ (1 − 3cg + 3cg²) / (S_ref D_ref²)

이 변환은 **원문에 없다** — 우리가 A.8·(8)·B.6 을 결합해 유도한 것이다.
그러므로 **원문 제공이 아니라 파생**으로 표기한다.

모멘트는 M→P 회전으로 **P 프레임 Z 성분**으로 돌아가므로 Y 성분만 보면
0 이다. 성분이 아니라 크기로 봐야 한다.

## 계약 정정 3건 (검토 반영)

### ① 공급자 인터페이스 — **일반 조립기로 확정**

감사 §4-2 는 정적 계수가 일반적으로 `(α_tot, φ_A, Mach)` 의 함수라고
적었는데 조립기는 `(α_tot, Mach)` 만 넘겼다. 그러면 같은 α_tot·Mach 에서
φ_A 만 다른 두 상태를 공급자가 구분할 수 없다. 동시에 `C_Ym`·`C_lm`·
`C_yawm` 의 비영 값을 허용하므로 축대칭 전용도 아니었다 — **두 계약 사이에
걸쳐 있었다.**

**일반 쪽으로 확정**하고 `φ_A` 를 넘긴다. 축대칭을 쓰려면 **공급자가**
φ_A 를 무시하고 정적 횡계수 3개를 0 으로 내면 된다 — 그 선택은 공급자의
것이지 조립기의 것이 아니다.

### ② `phi_eps` — 단위 의존이고 fail-closed 아니었다

`|vy|`, `|vz|` 를 절대값 `1e-12` 와 비교했다. **같은 물리 상태가 속도
단위에 따라 다르게 판정된다**(m/s 대 ft/s 에서 갈리는 것을 측정). 무차원으로
바꿨다:

```
hypot(vy, vz) / V_R <= phi_rel_eps          기본값 0 = 원문 그대로
```

원문 그대로면 `hypot(vy, vz) == 0` 에서만 규약값을 쓴다. 수치 근방 포함은
**별도 정책**이므로 인자로 분리하고 **유한·비음수를 검사**한다.

### ③ 비유한 fail-closed 가 파생값·출력에 없었다

측정으로 재현했다:

| 입력 | 결과 |
|---|---|
| 유한한 `1e308` 속도 성분 | `V_R = inf`, `Mach = inf` — **통과했다** |
| 유한한 `Q × S_ref` | 최종 힘 `−inf` — **통과했다** |

`sqrt(Σv²)` 를 **`math.hypot`** 으로 바꾸니 1e308 성분이 유한하게 나온다
(1.414e308). 그리고 **Mach·최종 F/M 까지 유한성을 검사**한다. 공급자
반환형 검사와 `Damping = None/NaN` 음성 회귀도 추가했다.

### ④ `phi_rel_eps` 에 상한이 없었다

`hypot(vy, vz) / V_R` 는 `sin(α_tot)` 이므로 1 을 넘을 수 없다. 그런데
상한이 없어 `phi_rel_eps = 1` 이상이면 **수직 횡류까지 특이점으로 삼켜**
`φ_A = 0` 을 냈다 — 측정하면 α_tot = 90° 인 상태가 φ_A = 0 이 된다.
"특이점 근방 허용오차"라면 반드시 1 미만이므로 **`[0, 1)`** 을 강제하고
`1`·`2`·`1e308` 음성 회귀를 붙였다.

## 변이 재확인

새 계약을 걸고 15종을 돌렸다. 살아남은 것은 **`V_R` 유한성 검사** 하나이며
포섭이다 — `v_sound` 가 유한 양수인 한 `V_R = inf ⇒ Mach = inf` 이므로 이
조항만 위반하는 입력이 없다. 방어로 남기고 그 사실을 코드에 적었다.

`φ_A` 전달은 처음에 **검사가 아예 없어** 변이가 살아남았다 — 차단 1 의
핵심인데도. 공급자 호출을 기록하는 검사를 추가해 고정했다.

## 부록 시험 공급자 (2026-08-15)

`appendix_suppliers.py` — **제한 조건용**이며 **기본 공력 모델이 아니다.**
계수를 지어내지 않는다: A 는 외부 `C_fin` 을, B 는 외부 교차류 계수 `C` 를
입력으로 받는다. 전제는 클래스 문서에 여섯 개씩 전부 적었다.

### 전제를 시험이 실제로 지키는가 — 첫 판은 아니었다

부록 A·B 의 **핵심 전제는 `α_tot = 90°` 교차류**인데, 첫 판 시험은
`V_R = (V, 0, 1e-9)` 즉 **α_tot ≈ 0° 축방향 흐름**으로 돌았고 부록 A 도
`α = 0` 으로 호출했다. 공급자가 각도를 무시했으므로 **전제 밖에서 조용히
통과했다.**

고친 것:

- 양성 픽스처를 `V⃗_R = (0, 0, V)` 로 — α_tot = 90°, φ_A = 0
- 공급자가 **비교차류 호출을 거부**한다 (`_require_crossflow`)
- 조립기를 통해 들어와도 거부된다

### `cg` 정의가 반대였다 — 시험으로는 못 잡는다

첫 판은 *"후단에서 잰 무게중심 위치 / L"* 이라 적었다. **원문 정의는
반대다**:

> *"distance from center-of-mass to **forward** end of cylinder, expressed
> as a fraction of cylinder length"*

후단 기준을 쓰려면 `1 − cg` 를 넣어야 한다. 그런데 다항식
`(1 − 3cg + 3cg²)` 는 **`cg ↔ 1−cg` 대칭**이라 수치가 같다 — 확인했다
(cg 0.2 와 0.8 이 둘 다 0.5200). **어떤 수치 시험도 이 오류를 잡을 수
없다.** 정의를 문서로 못 박는 수밖에 없다.

### 1% 조건이 다른 분모를 썼다

원문 조건은 **3항 대 2항**이다:

```
|D²q²| / |2 V D q| = |D q| / (2V) < 0.01
```

첫 판은 폐기항을 `Q_A2` **전체**와 비교해 훨씬 느슨했다 — 전제가 깨진
경우도 통과한다. B.1 → B.2 도 같은 조건을 **원통 전 구간의 최대 |X|**
에서 검사한다.

### 원통 형상 일관성

원문 정의상 `S_ref = πD_ref²/4` 다. 첫 판 픽스처의 `D_ref = 0.5`,
`S_ref = 2.0` 은 **일관된 원통이 아니다** — 대수는 우연히 닫히지만 출처
충실성 시험이 아니다. 생성자가 이제 이 관계를 **강제**한다.

### A — A.1–A.12 대수 재폐쇄

| 검사 | |
|---|---|
| A.1 → A.2 | `|Dq|/(2V) < 0.01` (원문 조건, 3항 대 2항) |
| B.1 → B.2 | 최대 `|X|` 에서 같은 조건 |
| A.4 = A.5 | `S_fin = S_ref/4` 대입 |
| A.7 원문형 = A.6 대입형 | 전사와 파생이 동치 |
| **A.8 = A.7** | `C_mmd` 경로와 직접 경로의 재폐쇄 |
| A.11·A.12 | `C_mqm = −C_fin` (교차류 안에서 호출) |
| 식 (8) 역산 | 되돌린 `C_mmd` 가 A.9 와 일치 |

### B — 두 경로 동등성

`moment_direct()` (B.6 그대로) 와 `c_mqm() → assembler` 를 **세
`(ρ, V_R, q_m)` 조합**에서 대조했다. 최대 상대차 **2.64e-16**, 판정
임계 **1e-12** — 첫 판은 `1e-9` 를 쓰고 `1e-12` 라 보고했다.

깨지는 것도 확인했다:

- **`Q` 를 1.5배로** 틀리게 주면 갈린다 (첫 판에는 이 검사가 없었다)
- `D ≠ D_ref` 면 갈린다
- `cg` 다항식이 `(1 − 3cg + 3cg²)` 로만 들어간다

**"상태 무관" 검사가 첫 판에서는 동어반복이었다** — 같은 무인자 함수를
두 번 불렀다. 지금은 **각 상태의 직접 모멘트에서 `C_mqm` 을 역산**해
```
C_mqm = 4 M_d / (ρ V_R q_m S_ref D_ref²)
```
세 상태의 역산값이 서로 같고 파생식과도 같은지 본다.

### 상태 독립의 범위

약분되는 것은 **`ρ`·`V_R`·`q_m` 뿐이다.** 외부 `C` 는 조건에 따라
달라지고 `cg` 도 질량특성 변화에 따라 달라진다. 그러므로 이 클래스는
**고정 `C`·`cg` 조건의 시험 공급자**이지 일반적으로 상태에 무관한
공급자가 아니다.

### 적용영역 구멍 둘 — 교차류만 봐서는 부족했다

**① `φ_A = 0` 을 검사하지 않았다.** 부록은 M·P·B 프레임 일치를 전제하므로
교차류만으로는 부족하다. 재현:

```
V⃗_R = (0, 100, 0)  →  α_tot = 90°, φ_A = 90°   ← 공급자 승인
조립기 M_Y = −0.000000     B.6 직접 = −107.520000
```

φ_A ≠ 0 이면 B→M 회전에서 **몸체 피치율이 M 프레임 피치율이 아니게 되어**
조립 결과가 직접 모멘트와 갈린다.

조립 경로에서만 보이는 전제는 **공급자 인터페이스가 `Reference` 를 받지
않으므로** 별도 함수 `require_assembly_premises()` 로 뒀다:

- **MRP = 무게중심** (부록은 무게중심 둘레 모멘트를 준다)
- 공급자와 `Reference` 의 `D_ref`·`S_ref` **일치**

**② `crossflow_tol_rad` 에 상한이 없었다.** `tol = π` 를 주면 α_tot = 0
축방향 흐름도 승인된다(재현). **`[0, π/2)`** 를 강제한다 — π/2 이상이면
전 범위를 덮어 전제가 무의미해진다.

### 비차단 셋

- `c_mqm()` 서술을 "상태 무관" → **"`ρ`·`V_R`·`q_m` 만 약분, 고정 `C`·`cg`
  조건에서만 상수"** 로 좁혔다
- B 의 폐기항 검사에 **음성 대조군**을 붙였다 — 없으면 `max|X|` 계산
  변이가 죽지 않는다
- `moment_direct()` 가 **음수 밀도·`V_R ≤ 0`·유한 입력의 곱 오버플로**를
  허용했다. 전부 거절한다

### 적용성 검사가 조립 경로에 안 걸려 있었다 — 장식이었다

`require_assembly_premises()` 를 정의하고 **시험에서만 따로 불렀다.**
부록 비교는 전부 일반 `assemble()` 을 직접 호출했으므로, MRP 가 1 m
어긋난 `Reference` 로도 **정상 반환**했다(재현).

**`assemble_appendix()` 래퍼**로 `적용성 검사 → 일반 assemble` 순서를
**구조적으로** 강제하고, 부록 시험은 전부 래퍼만 쓴다. 검사 함수를 따로
두기만 하면 호출자가 빠뜨릴 수 있고 **실제로 빠져 있었다.**

### 양성 사례 하나가 전제 밖이었다

`L = 4`, `cg = 0.4` → `max|X| = 2.4`:

| 사례 | \|qX\|/(2V) | |
|---|---|---|
| V=100, q=0.3 | 0.00360 | 통과 |
| V=250, q=−0.7 | 0.00336 | 통과 |
| **V=80, q=1.1** | **0.01650** | **위반** |

두 경로가 **같은 근사식에서 출발**하므로 전제 밖에서도 대수적으로
일치한다 — **일치만으로는 전제 준수의 증거가 되지 않는다.** 세 번째를
조건 안으로 내리고, **래퍼가 행마다** 폐기항 조건을 본다.

### 경계 사례가 있어야 `max(cg, 1−cg)` 가 고정된다

`max(cg, 1−cg) → cg` 변이가 처음엔 살아남았다. `cg = 0.4` 일 때 기존 두
사례는 **판정이 같아서**(둘 다 통과, 둘 다 위반) 못 잡는다:

```
V=80, q=1.1:  올바른 0.01650(위반)   변이 0.01100(위반)   같음
V=80, q=0.7:  올바른 0.01050(위반)   변이 0.00700(통과)   ← 가른다
```

**무게중심에서 먼 쪽 끝이 지배**한다는 것을 경계에서 검사한다.

### 비차단 둘

- `C` 는 교차류 **항력**계수이므로 **양수**여야 한다 — 음수를 허용했다
- `c_mqm()` 직접 호출에 **오버플로 검사**가 없었다

### 변이 12종 전부 죽는다

래퍼의 적용성 호출 제거, 래퍼의 폐기항 검사 제거, 폐기항 임계 완화,
`max(cg,1−cg) → cg`, φ_A 검사 제거, MRP 검사 제거, `D/S` 일치 검사 제거,
`C ≤ 0` 허용, `c_mqm` 유한성 제거, `3cg²` 누락, 음수 밀도 허용,
`V_R ≤ 0` 허용.

## A 경로의 같은 fail-open — 마지막 항목

B 를 닫는 동안 A 에 같은 구멍이 남아 있었다:

| 구멍 | 재현 |
|---|---|
| `d_ref` 가 선택적 → `truncation_ratio()` 가 `None` → **폐기항 검사 생략** | 실제 비가 1% 의 **250배**인데 통과 |
| `require_assembly_premises()` 가 `.d`/`.s` 만 탐색 → A 는 `.d_ref` 를 저장 | D 불일치가 통과 |

**선택적 속성 탐색이 다시 fail-open 을 만들었다.** 없앴다:

- `validate_reference(ref)` · `truncation_ratio(V_R, q_m)` 를 **필수 계약**으로
- 래퍼가 **조건 없이** 두 메서드를 호출
- A 의 `d_ref`·`s_ref` 를 **필수 생성자 인자**로, `S_ref = πD²/4` 도 강제
- 래퍼의 `q_m` 을 `pqr_b[1]` 대신 **조립기와 같은 B→M 변환** 결과로

A 도 이제 래퍼로 조립하는 회귀가 있다 — 첫 판은 `damping()` 만 직접 불러
이 구멍을 못 봤다.
