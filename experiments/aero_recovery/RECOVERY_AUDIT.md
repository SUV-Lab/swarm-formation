## 4. 회수한 식 — 본문 (1)–(18)

### 4-1. 각도·마하 (식 1–3, 3쪽)

```
α_tot = cos⁻¹( V_Rx / V_R )                     (1)   범위 0°~+180°, 음수 없음
φ_A   = tan⁻¹( V_Ry / V_Rz )                    (2)   범위 −180°~+180°
MACH  = V_R / V_sound                           (3)
```

`V_Rx, V_Ry, V_Rz` 는 **B 프레임의 V⃗_R 성분을 MRP 로 옮긴 것**.

### 4-2. 정적 계수 6개 (2–3쪽)

```
C_Am    축력      C_Ym    측력      C_Nm    법선력
C_lm    롤 모멘트  C_mm    피치 모멘트  C_yawm  요 모멘트
```

**부호 규약**: `C_Am`, `C_Nm` 은 각각 **X축·Z축의 반대 방향이 양**.
모멘트 셋은 **오른손 법칙**으로 양.

**축대칭 단순화 (원문 명시)**: 중심선 축대칭이면 M 프레임의 X-Z 평면이
V⃗_R 을 포함하는 대칭면이므로 **정적 횡방향 계수 3개(`C_Ym`, `C_lm`,
`C_yawm`)를 0 으로 둘 수 있다.**

**범위 주의**: 0 이 되는 것은 **정적** 계수 셋뿐이다. 각속도가 만드는
롤·요 **감쇠**(`C_lmd`, `C_yawmd`, 식 7·9)는 제거되지 않는다. 1회차가
"남는 것은 셋"이라 적은 것은 정적 계수에 한정해야 한다.

의존 변수: 일반적으로 (α_tot, φ_A, Mach). **축대칭이면 (α_tot, Mach) 뿐**
— φ_A 에 무관.

### 4-3. 감쇠 미계수 (식 4–6, 5쪽)

```
C_lpm   = ∂C_lm   / ∂( p_m · D_ref / (2 V_R) )      (4)
C_mqm   = ∂C_mm   / ∂( q_m · D_ref / (2 V_R) )      (5)
C_yawrm = ∂C_yawm / ∂( r_m · D_ref / (2 V_R) )      (6)
```

무차원화 인자는 **`D_ref / (2 V_R)`** — 항공기 관례의 `b/(2V)`, `c̄/(2V)`
와 달리 **세 축 모두 `D_ref`** 를 쓴다.

**적용 지점 규약** (5쪽, 중요):
- 감쇠 미계수는 **MRP 가 아니라 무게중심(에 가까운 곳)** 에서 개발한다
- 좌표계는 **M 프레임에 평행**하고 원점은 중심선 위 무게중심의 X 위치
- 개발 후 **MRP 에서 M 프레임으로 적용**한다 (순수 우력이므로 어느 점에나 적용 가능)
- 중심선에서의 작은 횡방향 무게중심 편차는 무시

각속도 `p_m, q_m, r_m` 은 **B 프레임 몸체 각속도를 중심선 둘레로
`−φ_A` 회전**시켜 얻는다.

### 4-4. 감쇠 모멘트 계수 (식 7–9, 6쪽)

계수와 각속도의 **선형 관계 가정**:

```
C_lmd   = ( p_m · D_ref / (2 V_R) ) · C_lpm         (7)
C_mmd   = ( q_m · D_ref / (2 V_R) ) · C_mqm         (8)
C_yawmd = ( r_m · D_ref / (2 V_R) ) · C_yawrm       (9)
```

### 4-5. M 프레임 힘·모멘트 (식 10–11, 7쪽)

```
F⃗_m = Q · S_ref · [ −C_Am , C_Ym , −C_Nm ]ᵀ                        (10)

M⃗_m = Q · S_ref · D_ref · [ C_lm + C_lmd ,
                             C_mm + C_mmd ,
                             C_yawm + C_yawmd ]ᵀ                    (11)
```

식 (10) 의 **1·3 성분에 음부호**가 붙는 것이 §4-2 의 부호 규약과 맞물린다.
모멘트는 `S_ref · D_ref` 로 차원화한다 — 세 축 공통.

### 4-6. M → P 변환 (식 12–13, 7쪽)

중심선 둘레로 공력 롤각 `φ_A` 회전:

```
        ⎡ 1     0        0    ⎤
R_pm =  ⎢ 0   cos φ_A  sin φ_A ⎥        F⃗_p = R_pm F⃗_m   (12)
        ⎣ 0  −sin φ_A  cos φ_A ⎦        M⃗_p = R_pm M⃗_m   (13)
```

### 4-7. P → B 변환 (식 14–18, 7–8쪽)

```
F⃗_b = F⃗_p                                                          (14)
M⃗_b = M⃗_p + MRP⃗_b × F⃗_p                                           (15)

M_Xb = M_Xp + MRP_Yb·F_Zp − MRP_Zb·F_Yp                             (16)
M_Yb = M_Yp + MRP_Zb·F_Xp − MRP_Xb·F_Zp                             (17)
M_Zb = M_Zp + MRP_Xb·F_Yp − MRP_Yb·F_Xp                             (18)
```

`MRP⃗_b` 는 **무게중심 기준 MRP 위치**(B 프레임).

### 4-8. 식 (2) 의 구현 계약 — `atan2` 와 끝점 규약

원문 식 (2) 는 `tan⁻¹(V_Ry/V_Rz)` 로 적혀 있으나 **범위가 −180°~+180°**
이므로 구현은 **`atan2(V_Ry, V_Rz)`** 여야 한다. 단순 `atan(y/z)` 는
−90°~+90° 만 낸다.

그리고 원문이 직접 못 박는 것을 1회차가 놓쳤다 (3쪽):

> *"It is imperative to note that **singularities exist in the φ_A equation
> at α_tot = 0° and 180°**, and these must be handled by **specifying a value
> of φ_A (such as 0°)** for these two values of α_tot."*

끝점에서 V⃗_R 이 X 축과 평행해 `V_Ry = V_Rz = 0` 이 되므로 φ_A 가 정의되지
않는다. **명시적 규약이 필수**이고 원문은 0° 를 예로 든다.

## 4-9. 부록 — 1회차가 통째로 빠뜨린 것

1회차는 "식 (1)–(18) 전부"라고 적었으나 **본문만 다뤘다.** 원문에는
부록 A.1–A.12, B.1–B.6 이 더 있고, **단순 설명이 아니라 사용 가능한
해석식을 포함한다.**

### A — 감쇠 미계수의 등가 (제한된 예제)

```
C_mmd = −( q_m · D_ref / (2 V_R) ) · C_fin                          (A.9)
C_mmd = (∂C_mm / ∂q_m) · q_m                                        (A.10)
C_fin = −∂C_mm / ∂( q_m D_ref / (2 V_R) )                           (A.11)
C_mqm =  ∂C_mm / ∂( q_m D_ref / (2 V_R) )                           (A.12)
```

(A.11) 과 (A.12) 의 우변이 부호만 다르므로:

> **`C_mqm = −C_fin`** — 피치 감쇠 미계수는 수평 미익의 법선력 계수의
> 음수와 같다.

**전제**: 부록 A 가 세운 **단순 예제**(수평 미익 하나)에 한한다. 일반
형상으로 확장되지 않는다.

### B — 교차류 원통의 피치 감쇠 모멘트 (해석식)

```
M_di = −ρ V_R q_m C X² D dx                                          (B.5)

M_d  = −(1/3) ρ V_R q_m C D L³ (1 − 3·cg + 3·cg²)                    (B.6)
```

`cg` 는 무차원 무게중심 위치, `L` 은 원통 길이, `C` 는 교차류 계수,
`D` 는 직경. 원문이 밝히듯 **피치 감쇠가 무게중심 위치와 원통 길이에
크게 민감**하다는 것을 보인다.

**전제**: 교차류 조건의 원통(미익·노즈콘 제외), 정적 항 제외.

### 5-1. 가장 중요한 공백

> **원문은 계수의 *구조·프레임·차원화·적용 순서* 를 준다. 일반 계수 *값*
> 은 주지 않는다. 다만 제한된 형상·가정 아래 해석식 일부는 제공한다.**

`C_Am`, `C_Nm`, `C_mm` 을 α_tot × Mach 격자에 채우는 것은 별도 자료가
필요하다. 감쇠 쪽은 1회차가 "전부 외부 자료 필요"라 적었으나 **너무 넓다**
— 부록 A·B 가 제한된 조건의 해석식을 준다(§4-9).

**이것은 "회수 실패"가 아니다.** 회수한 것은 **틀 전체**이고, 그 틀이
요구하는 입력 목록이 위 표다. 자체 추정으로 계수를 만들더라도 **이 틀에
꽂아 넣으면 프레임·부호·차원화를 스스로 정하지 않아도 된다** — 그것이
이 회수의 값이다.

## 6. 저동압·저속·큰 받음각 적용성 — 별도 판정

| 영역 | 판정 | 근거 |
|---|---|---|
| 큰 받음각 (0°~180°) | **기구학적 표현만 보장** | 식 (1) 이 그 범위를 표현하도록 정의된다. **계수의 물리적 유효범위는 원문이 주지 않는다** |
| α_tot = 0° / 180° 끝점 | **명시 규약 필요** | φ_A 가 정의되지 않는다. 원문이 0° 같은 값을 지정하라고 못 박음(§4-8) |
| 롤 자세 전 범위 | 기구학적 표현만 보장 | M 프레임이 V⃗_R 을 X-Z 평면에 고정 |
| **저속·저동압** | **원문이 판정하지 않는다** | §6-1 |

### 6-1. 저동압에서 무엇이 무너지는가 — 형식적 검토

원문은 속도 하한을 논하지 않는다. 식에서 직접 보이는 것:

1. **식 (1) `α_tot = cos⁻¹(V_Rx / V_R)`** — `V_R → 0` 에서 정의되지 않는다.
   0으로 나누기.
2. **식 (4)–(9) 의 `D_ref / (2 V_R)`** — `V_R → 0` 에서 발산한다. 감쇠
   모멘트 계수가 무한대로 간다.
3. **식 (10)–(11) 의 `Q`** — `Q → 0` 이므로 힘·모멘트는 0 으로 간다.

2와 3이 상쇄되는지는 **곱을 보면 유한**하다:

```
M ∝ Q · S_ref · D_ref · (q_m D_ref / (2 V_R)) · C_mqm
  ∝ (½ ρ V_R²) · (q_m / V_R)
  ∝ ρ V_R q_m          →  V_R → 0 에서 0
```

즉 감쇠 모멘트 자체는 유한하고 0 으로 간다. **발산하는 것은 무차원 계수
`C_mmd` 이지 모멘트가 아니다.** 다만 구현이 계수 단계에서 클램프하면
그 클램프가 물리를 바꾼다.

**전제를 명시한다** — 이 상쇄 논증은 `ρ`, `q_m`, `C_mqm` 이 저속에서
**유한**하다는 가정 위에서만 성립한다. 정적 힘도 마찬가지로 `C_Am`,
`C_Nm` 이 저속·저 Mach 에서 유한해야 `Q → 0` 이 힘을 0 으로 보낸다.
**원문에 계수값이 없으므로 이 유한성은 확인되지 않았다.**

**식 (1) 은 상쇄되지 않는다** — `V_R → 0` 에서 α_tot 자체가 정의되지
않으므로 정적 계수를 조회할 인자가 없다.

### 6-2. 판정

> **저동압·저속 영역의 적용성은 원문으로 판정할 수 없다.** 문서는 상승과
> 재진입을 대상으로 하며 속도 하한을 명시하지 않는다. 식 수준에서는
> 감쇠 모멘트가 유한하게 0 으로 가지만, **α_tot 정의가 V_R → 0 에서
> 무너지므로 정적 계수 경로에 하한이 필요하다.** 그 하한값은 원문이
> 주지 않는다.

초기 수직 구간의 시작 속도가 0 이 아님(ADR-0003 §2 경우 B)은 이 문제를
**완화하지만 제거하지는 않는다** — 하한을 얼마로 둘지는 여전히 결정 사항이다.

## 7. 중단 조건 대조

| 조건 | 해당 | 비고 |

## 부록 A — 영상 판독 결과 (1회차 미포함분)

```
Q_fin = ½ρ(V_R² + 2V_R D_ref q_m + D_ref² q_m²)                     (A.1)
Q_fin = ½ρ(V_R² + 2V_R D_ref q_m)          ← 3항 무시              (A.2)
F_fin = Q_fin C_fin S_fin                                            (A.3)
M_fin = −Q_fin C_fin S_fin D_ref                                     (A.4)
M_fin = −(1/4) Q_fin C_fin S_ref D_ref     ← S_fin = S_ref/4        (A.5)
Q_d   = ρ V_R D_ref q_m                    ← 감쇠 항만              (A.6)
M_d   = −(1/4) ρ V_R q_m C_fin S_ref D_ref²         ← 원문 전사        (A.7)
M_d   = ½ ρ V_R² S_ref D_ref C_mmd         ← 일반형                 (A.8)
C_mmd = −(q_m D_ref / 2V_R) · C_fin                                  (A.9)

  파생(원문 아님): A.6 을 A.5 에 대입하면 A.7 은 −¼ Q_d C_fin S_ref D_ref
  와 동치다. 1회차는 이 동치식을 원문 전사로 적었다.
C_mmd = (∂C_mm/∂q_m) · q_m                                          (A.10)
C_fin = −∂C_mm / ∂(q_m D_ref / 2V_R)                                (A.11)
C_mqm =  ∂C_mm / ∂(q_m D_ref / 2V_R)                                (A.12)
```

### A 의 전제 — 1회차는 "수평 미익 하나"로만 적었다. 여섯 개다

원문이 명시하는 전제 전부:

1. **후미 수평 미익 하나가 피치 감쇠 전부를 담당** (*"not necessarily
   realistic"* 이라고 원문이 스스로 단서를 단다)
2. **미익–무게중심 거리 = `D_ref`** — *"solely for the purpose of obtaining
   a final result without inserting additional constants"*
3. **M·P·B 세 프레임이 일치**, 원점은 중심선 위 무게중심, Z 하향
4. **교차류 조건** 가정
5. **`q_m²` 항 무시** (A.1 → A.2, 2항 대비 1% 미만)
6. **`S_fin = S_ref / 4`** — 역시 상수를 안 넣기 위한 가정

**`C_mqm = −C_fin` 은 이 여섯 전제 아래에서만 성립한다.**

## 부록 B — 영상 판독 결과

```
Q    = ½ρ(V_R² − 2V_R q_m X + q_m² X²)                              (B.1)
Q    = ½ρ(V_R² − 2V_R q_m X)               ← 3항 무시 (약 1%)       (B.2)
F_i  = ½ρ(V_R² − 2V_R q_m X) C D dx                                 (B.3)
M_i  = ½ρ(V_R² − 2V_R q_m X) C X D dx                               (B.4)
M_di = −ρ V_R q_m C X² D dx                ← 정적 항 제외           (B.5)
M_d  = −(1/3) ρ V_R q_m C D L³ (1 − 3cg + 3cg²)                     (B.6)
```

**전제** (1회차는 셋만 적었다):

1. **교차류 조건**의 원통 — 미익·노즈콘 제외
2. **무한 원통 공력 특성** 가정, **끝단 유동 없음**
3. **M·P·B 프레임이 무게중심에서 일치**
4. **`C` 가 원통 크기·증분 면적 크기에 따라 변하지 않는다** 는 가정
5. **`q_m² X²` 항 무시** (B.1 → B.2, 2항 대비 약 1%)
6. **정적 항 제외** (B.4 의 첫 항)

### B.6 은 `C_mqm` 을 직접 주지 않는다

1회차 표가 *"(B.6) 이 `C_mqm` 값을 직접 준다"* 는 식으로 읽히게 적었다.
**틀렸다** — B.6 은 **`M_d` (모멘트)** 다. `C_mqm` 으로 가려면 A.8 과
식 (8) 을 거쳐야 한다:

```
A.8:   M_d   = ½ ρ V_R² S_ref D_ref C_mmd
(8):   C_mmd = (q_m D_ref / 2V_R) C_mqm
  ⇒    C_mqm = 4 M_d / (ρ V_R q_m S_ref D_ref²)

B.6 대입 ⇒  C_mqm = −(4/3) C D L³ (1 − 3cg + 3cg²) / (S_ref D_ref²)
                  = −(4/3) C L³ (1 − 3cg + 3cg²) / (S_ref D_ref)   [D = D_ref]
```

이 변환은 **원문에 없다** — 우리가 A.8·(8)·B.6 을 결합해 유도한 것이다.
그러므로 **원문 제공이 아니라 파생**으로 표기한다.
