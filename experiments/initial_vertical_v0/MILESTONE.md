# 6DOF 초기 수직 구간 — 마일스톤 마감

**동결일 2026-08-17**

| | |
|---|---|
| 브랜치 | `lgh/initial-vertical-6dof` (상위·서브모듈 동명) |
| 태그 | `mmp/6dof-supplier-contract-v1` |
| 상위 커밋 | `8c6bc5b` |
| 서브모듈 커밋 | `42fcc42` |
| 분기 기준 | `lgh/dev` (`0a2ed22`) 에서 59 커밋 앞섬 |

여기서 멈추는 것은 포기가 아니라 **외부 데이터가 필요한 경계까지 구현을
완료한 것**이다. 더 진행하면 근거 없는 계수를 가정하며 시험 모델만
정교해지고, 실제 적용 가능성은 높아지지 않는다.

## 1. 현재 가능한 것

| | 상태 | 근거 |
|---|---|---|
| 기존 3DOF 초기 플래너 ↔ 중기 연결 | **완료·동결** | `mmp/initial-planner-rc1` |
| 6DOF 실행 엔진 (JSBSim 전파) | **완료** | 정확한 초기 수직 PVA → 자세·각속도·질량·CG 전파 |
| 결합 인계 관문 (2단계 AND) | **완료** | 매 시각 `sixdof_ready` → PVA 투영 → 중기 포락선, 둘 다 통과해야 dwell |
| 포락선 판정 공용화 | **완료** | 생산과 **같은** `handoffVerdict`. 오프라인 하니스가 재유도하지 않는다 |
| 항력식 공용화 | **완료** | `dragCoefficient` 하나 |
| 시험 모델에서 성공·거부 경로 검증 | **완료** | 양성대조 1 · 진단 2 · 음성대조 3, 변이시험으로 하중 확인 |
| 요구조건 역산 A (경로) | **완료** | 최초 진입 계약, 네 판정 분리 |
| 요구조건 역산 B (회전 권한) | **완료** | 무차원량만 보고, 정착시간 fail-closed |
| 공급 계약 초안 | **완료** | [SUPPLIER_DATA_CONTRACT.md](SUPPLIER_DATA_CONTRACT.md) |
| 데이터 누락 시 | **fail-closed** | 값을 지어내지 않고 거부 |

## 2. 아직 확정하지 못한 것

| 항목 | 상태 | 왜 |
|---|---|---|
| `CL(α, M)` 비선형 · `CL_max(M)` | **UNKNOWN** | 목표 대역 공개 자료 없음 |
| `Cm(α, M)` | **UNKNOWN** | 공력중심 이동 근거 없음 |
| `Cm_q` (대역 내) | **UNKNOWN** | 식 (3) 이 실측 구성 증분과 17.5% 어긋나 닫히지 않음 |
| `Cm_αdot` | **UNKNOWN** | 회수 자료 없음 |
| `Cm_q + Cm_αdot` 합 | 진단 전용 | 두 계수가 `q`·`α̇` 라는 다른 입력에 곱해져 일반 6DOF 전파 불가 |
| `CL_α(M)` | 관계는 회수·검산 | TN 3911 (A1). **미연결** — 출처가 유효 받음각 범위를 주지 않음 |
| 질량·CG·관성 | 근거 없는 시험값 | 실기 질량배치 자료 없음 |
| 실기 형상 | **미정** | TR 1096 은 **시험·인터페이스 검증용**이지 실기 형상이 아님 |
| **물리적 성립성** | **UNKNOWN** | 가능·불가능 **어느 쪽도 판정하지 않음** |

> 마지막 줄이 이 마일스톤의 결론이다. "안 된다" 가 아니라 "현재 공개
> 근거로는 판정할 수 없다" 이다.

## 4. 산업체에 요청할 것

전체 계약은 [SUPPLIER_DATA_CONTRACT.md](SUPPLIER_DATA_CONTRACT.md) 에 있다.
요청 목록만 여기 모은다.

### 4-1. 자료 (표·파일로 줄 경우)

| 항목 | 필수 | 비고 |
|---|---|---|
| 질량 · CG · `Ixx Iyy Izz Ixz` | 필수 | **시간 변화 포함**, 기준점 명시. "대략 일정" 은 받지 않음 |
| `CL(α,M)` `CD(α,M)` `Cm(α,M)` | 필수 | 비선형 영역 포함, **부호 있는** α |
| `CL_max(M)` | 필수 | 표에서 유도하지 말 것 |
| `Cm_q(α,M)` `Cm_αdot(α,M)` | 필수 | **단독**. 합만 있으면 합으로 표기 |
| `Cm_δe(α,M)` · 액추에이터 한계 | 제어면 있으면 | 편향·편향률 한계 |
| 유효 마하 · 받음각 · 옆미끄럼각 범위 | 필수 | **부호 있는** 범위. 정성 진술 불가 |
| 파탄 조건 | 필수 | 없으면 "없음" 이라고 적을 것 |
| 값별 출처 등급 | 필수 | MEASURED / MEASURED_DIGITIZED / CFD / ESTIMATED / UNKNOWN |

### 4-2. 기준 벡터 (계수를 공개하지 않아도 가능)

**이것만 있으면 좌표계와 배관을 검증할 수 있다.**

```
입력   상태     V, α, β, p, q, r, α̇
     + 환경     고도, 밀도 또는 마하, 동압
     + 조종     승강타 편향, 추력
출력   기대 힘·모멘트 (몸체축, CG 둘레)
     + 질량 · CG · 관성
     + **각 출력마다의 허용오차**
```

사례는 **유효 범위의 안쪽·경계·밖**을 함께 덮어야 한다. 범위 밖 사례로
`in_range = 0` 이 실제로 나오는지 확인한다.

### 4-3. 규약 (이것이 비면 나머지가 무의미하다)

좌표계 · 각도 단위 · 기울기 단위(`/rad` vs `/deg`) · 피치율 무차원화
(`q c̄/(2V)` vs `q l/V`) · 기준면적 · 기준길이 · 모멘트 기준점 · 대기 모델.

> 이번 작업에서 실제로 나온 오류가 전부 이 범주였다: **57.3배**
> (per deg ↔ per rad), **2배와 기준길이비 제곱**(피치율 무차원화),
> **3.537배**(양력 기준면적에 동체 단면적).

### 4-4. 합의 항목

제공 형태(표/파일 vs 실행 모듈) · 기준 사례 제공 여부 · **출력마다의**
허용오차 · 범위 밖 동작 · **버전과 데이터 변경 식별 방식**.

버전 식별이 특히 중요하다. 받는 쪽 회귀가 값을 단언하므로 자료가 바뀌면
회귀가 깨져야 하고, 그때 무엇이 바뀌었는지 알 수 있어야 한다.

## 5. 운영 브랜치 상태

- 실험 6DOF 코드는 **운영 브랜치에 합치지 않았다.** 작업 브랜치
  `lgh/initial-vertical-6dof` 에만 있고, `lgh/dev` 에도 아직 합치지 않았다
- `experiments/initial_vertical_v0/` 에 `COLCON_IGNORE` — 생산 빌드에 들어가지 않는다
- 생산 코드에 들어간 것은 **공용화 두 건뿐**이며 둘 다 회귀 통과:
  - `mmp_vehicle_dynamics::handoffVerdict` / `speedConeVerdict` — `PathManager::pvaEnvelopeProblem` 이 이제 얇은 래퍼
  - `mmp_vehicle_dynamics::dragCoefficient` — 항력식 한 곳
- **main 머지는 승인 대기.** 상위 `main` 은 `376930c` 에서 변경 없음
- `mmp/initial-planner-rc1` 태그 동결 유지

## 6. 재개 조건과 순서

### 재개 신호 (셋 중 하나)

1. 산업체 데이터 **형식이 확정**됨
2. **기준 입력·출력 벡터**를 받음
3. 일반 시험 모델을 **제품 기능으로 만들라는 별도 요구**가 생김

### 재개 순서

```
6-1 규약 검사        단위·축·부호·무차원화. 엄격한 수치 검사
      ↓
6-2 기준 벡터 재현    좌표계와 배관이 맞는지. 물리 정확성은 말하지 않음
      ↓
시간 전파            6DOF 실행 엔진에 실제 공력 연결
      ↓
중기 인계            결합 관문 2단계, 적용범위 창 재측정
      ↓
운영 연결            생산 경로 배관
```

### 재개 시 유의

**회귀가 값을 단언하고 있다.** `run_cases.sh` 가 적용범위 집계·분류
개수·직접 전환 증인·회전 권한 무차원량을 전부 값으로 못박으므로, 계수를
주입하면 **의도적으로 깨진다.** 결함이 아니라 설계다. 기대값을 갱신하면서
무엇이 왜 바뀌었는지 적는 것이 재개의 첫 기록이 된다.

그리고 **실기 형상을 TR 1096 과 대조하지 않는다**(계약 §6-4). 서로 다른
형상이라 차이의 원인을 구분할 수 없다.
