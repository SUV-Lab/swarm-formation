# v0 초기 수직 구간 end-to-end — 실행 결과

**이 문서의 모든 수는 실행 엔진 검증이다. 실제 비행 가능성의 근거가 아니다.**
파라미터는 전부 `DECLARED_TEST` 이며 실제 플랫폼 값이 아니다. 공력 계수
(`cm_alpha`, `cm_q`, `cl_alpha`)는 `UNKNOWN` 이라 **지어내지 않았고**, 그래서
기체의 공력 항 자체를 뺐다. 여기서 나오는 궤적은 추력과 중력만의 궤적이다.

재현:

```
cmake -S . -B .build -DJSBSIM_ROOT=<inst> -DMMP_DYN_ROOT=<mmp_vehicle_dynamics>
cmake --build .build -j4
./.build/v0_harness --root . --tmax 120 --csv v0_vertical.csv
```

종료 코드 — 0 인계+영역진입 / 1 측정됨·미도달 / 2 실행 오류 / 3 계약 위반.

돌고 있었다.

## 3. 인계 7항목 — **미도달**

120 s 안에 7항목 동시 충족 1.0 s 지속에 이르지 못했다. 경로각이 목표
(20°)에 가장 가까웠던 순간은 t = 28.294 s, 그때의 개별 판정:

| # | 항목 | 판정 | 값 | 한계 |
|---|---|---|---|---|
| 1 | 경로각 정렬 | 통과 | −0.00864° | 2.0° |
| 2 | 받음각 | 통과 | 3.45811° | 12.0° |
| 3 | 옆미끄럼각 | 통과 | −0.82704° | 3.0° |
| 4 | 자세 오차 | 통과 | 3.45608° | 5.0° |
| 5 | 몸체 각속도 | **실패** | 6.72219 °/s | 5.0 |
| 6 | 제어 여유 | 통과 | 0.99263 | 0.20 |
| 7 | 속력 하한 | **실패** | 36.33539 m/s | 131.76 |

**막은 것은 속력이다.** 경로각은 맞출 수 있지만 그 시점 속력이 중기 순항
하한의 28% 다. 공력이 0 이면 속도 벡터를 돌리는 힘은 추력의 수직 성분뿐이고
(T/W = 0.25), γ = 90° 근처에서는 중력의 선회 기여 `g·cos γ` 가 0 이라
선회가 거의 되지 않는다. 결국 상승분을 다 잃고 나서야 경로각이 내려온다.

이것은 **선회 권한이 공력 수직력에 있다**는 뜻이고, 그 계수가 바로 매니페스트의
`UNKNOWN` 세 항목이다. 즉 미상값은 장부상의 빈칸이 아니라 이 구간의 핵심
물리량이다.

PVA 투영과 중기 유효영역 판정은 **수행하지 않았다** — 7항목 전부 통과가
전제이기 때문이다.

## 4. 하니스 양성대조 (초기 γ = 25°, 수직 구간 측정이 아님)

하류 단계(투영·유효영역)가 실제로 도는지 확인하기 위한 실행이다.

- 인계 도달: t = 2.3360 s, 7항목 전부 통과 (연속 1.00 s)
- 투영 PVA: p = (0, 0, 2203.039) m, v = (213.76571, −0.02958, 76.56068) m/s,
  a = (2.30689, −0.01113, −8.91475) m/s²
- 투영 검산 잔차 (추력 제외) = (0.00000, −0.01116, 9.77349) m/s².
  중력만 남아야 하며 잔차는 지구자전 겉보기항 상한 0.06704 m/s² 이내다.
- **중기 유효영역 진입: 아니오.** 포락선 사용률 1.27101, 제한 요소 최대 추력.

### 진단 — 왜 영역 밖인가 (판정 기준 아님)

같은 PVA 를 항력 0 으로 다시 재면 사용률 1.27101 → 1.00447 이다.

- 두 모형의 **항력 불일치**가 0.26654 를 차지한다. v0 6DOF 는 공력이 0 이라
  항력이 없고, 생산 3DOF 는 `zero_lift_drag_coefficient = 0.035` 를 싣는다.
- 남는 1.00447 은 항력을 지워도 선언 추력 3200 N 이 이 인계 PVA 에 **간당간당**
  하다는 뜻이다. 항력만의 문제가 아니다.

원인 주장을 말로 두지 않고 실측으로 갈랐다.

## 5. 음성대조 3종

| 대조군 | 기대 | 실제 | 종료 코드 |
|---|---|---|---|
| `missing_param` — UNKNOWN 을 필수로 요구 | 값을 지어내지 않고 정지 | `cm_alpha` 에서 정지 | 3 |
| `weak_control` — 가용 모멘트 0.1% | 권한 부족이 특정 항목으로 드러남 | 최근접 순간 **제어 여유 0.00000** 단독 실패 | 1 |
| `nonfinite` — t ≥ 1 s 에 NaN 주입 | 상태 관문이 포착 | t = 1.0040 s 에서 포착 | 3 |

`weak_control` 이 수직 실행과 **다른 항목**(속력·각속도가 아니라 제어 여유)에서
실패하므로, 관문이 구별력을 갖는다는 것이 확인된다.

## 6. 이 실행이 보이지 않는 것

- 실제 플랫폼의 비행 가능성. 파라미터가 전부 `DECLARED_TEST` 다.
- 공력이 있는 기체의 거동. 계수가 `UNKNOWN` 이라 항 자체가 없다.
- 제어면 설계. 가용 피치 모멘트를 직접 선언했을 뿐 `Cm_δe` 는 모른다.
- 적분기 선택의 타당성. AB2/Buss2 로 고정했고 ADR-0003 §11-A 의 보류가 그대로다.

## 7. v0 이 남긴 결정거리

1. 공력 0 인 6DOF 가 만든 인계 PVA 는 생산 3DOF 가 재현하지 못한다 (사용률
   1.271). **두 모형의 항력이 먼저 일치해야 인계가 성립한다.**
2. 항력을 지워도 사용률 1.004 — 선언 추력 3200 N 자체가 이 인계 조건에
   여유가 없다.
3. 인계 7항목에 **포락선 항목이 없다.** 양성대조는 7항목을 전부 통과하고도
   유효영역 밖이었다. 관문 집합에 중기 포락선 검사를 넣을지 결정해야 한다.
