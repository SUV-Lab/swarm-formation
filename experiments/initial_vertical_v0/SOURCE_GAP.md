# 공개 자료 공백 — 탐색 종료 기록

**결론: 검토한 중립적 공개 자료만으로 목표 영역의 필수 계수를 확보하지
못했다.** "공개 자료가 존재하지 않는다" 는 뜻이 아니다 — 이 프로젝트의
중립성·권리 조건을 통과하면서 목표 마하 대역과 부호 있는 받음각을 함께
덮는 것을 찾지 못했다는 뜻이다.

문헌 탐색은 여기서 **종료**한다. 형상을 자료에 맞춰 바꾸거나 수용조건을
넓히지 않는다 — 둘 다 시험이 통과하도록 문제를 바꾸는 것이다.

공급자는 계속 fail-closed 다. `v0_aero.cpp` 의 `liftSlopeRatio` 와
`pitchDampingInBand` 는 거부한다.

---

## 1. 수용조건

| | 조건 |
|---|---|
| (a) | 마하 0.3585 ~ 0.7000 |
| (b) | **부호 있는** 받음각, 현재 요구 기준 대략 −25°~+25°. 음의 받음각을 양의 자료 **반사로 만들면 실격** |
| (c) | 비선형 `CL(α,M)` 과 `Cm(α,M)` 을 **각각** 제공 |
| (d) | 기준면적·기준길이·모멘트 원점을 현재 형상으로 변환 가능 |
| (e) | 고받음각·박리 영역의 **명시된** 적용 근거 |
| (f) | 공개 이용 권리 **및** 도메인 중립성 |

우선순위: **형상을 입력받는 공개 방법 > 다른 형상에서 측정한 표.**
후자를 쓰면 다른 비행체를 계산하게 된다.

(b) 의 반사 금지 근거: 우리 형상 자신의 실측이 `CL(0) = +0.005`,
`Cm(0) = +0.019` 로 영점에서조차 완전한 홀대칭이 아니고, 비선형 영역에서
대칭 가정은 더 약해진다.

## 2. 후보별 탈락 사유

### 형상입력 방법

| 후보 | 탈락 |
|---|---|
| **NASA TR R-474** (Jorgensen 1977, NTRS 19770026166) | (a) 날개+꼬리 검증 하한이 M 0.6 — 0.3585~0.6 이 통째로 빈다. 원문 스스로 *"with a decrease in Mach number to M∞ = 0.6, the agreement for CN rapidly deteriorated"*. (b) α 0°~60°, 음수 없음. (c) `CN`·`Cm` 은 분리 출력이나 `CL` 은 *"rough engineering estimates"* 인 `CA` 경유. (f) 권리는 공개이나 중립성 실패 — 보고서 목적 자체가 제한 도메인 |
| **NASA TN D-3767** (Polhamus 1966, 앞전 흡입력 유추) | (a) 저아음속 한정. (b) 음수 없음. (c) **`Cm` 을 주지 않는다** — 원문이 후속 과제로 명시. (d) 날개 단독 |
| **NASA TN D-6994** (1972) | `Cm` 은 주지만 삼각날개 AR ≤ 2, α 0°~30°, M 0.2, 동체·꼬리 없음 |
| **NASA TR R-428** (Lamar 1974) | 출력 형태는 가장 근접(양력·항력·피칭모멘트). 그러나 시험이 **M 0.20 단일점**, 음수 α 없음, **날개 단독** |
| Multhopp / Weissinger 계열 | 부착유동 선형 lifting-surface 이론. 비선형 확장은 저널 논문이라 권리 실패이고, 구조적으로 **2차원 익형 데이터를 입력으로 요구** — 그것이 없어서 시작된 문제라 순환이 된다 |

### TR R-474 의 독립 실격 사유

(a)~(f) 와 별개로, 그 방법이 퍼텐셜 항으로 쓰는 N-K-P(NACA Rep. 1307)의
적용 제한이 우리 형상을 배제한다. 원문:

> *"restricted to bodies of circular cross section with wings and tails that
> do not have swept-forward leading edges or **swept-back trailing edges**."*

우리 날개(A 4.0, 테이퍼 0.6, 1/4시위 45°)의 시위별 후퇴각을 직접 계산하면

```
앞전 46.736° · 1/4시위 45.000° · 반시위 43.152° · 뒷전 39.094°
```

**뒷전이 39.09° 후퇴**하므로 제외 조건에 걸린다.
(`tan Λ_TE = tan45° − (4/A)(0.75)(1−λ)/(1+λ) = 0.8125`)

또 검증에 쓴 날개는 *"five flat-plate wings"* 로 평판이며 65A008(두께 8%,
둥근 앞전)이 아니다.

### 전체 형상 풍동 자료

**전 후보가 (b) 에서 탈락한다.** wing+body+tail 형상에 대해 **−8° 보다 더
음의 받음각을 시험한 사례를 하나도 찾지 못했다.** (a) 마하 하한 0.3585 가
두 번째 병목이다.

## 3. TR 1096 주변에 고마하 동반 시험은 없다

- 시험 시설(Langley stability tunnel)이 **저속 전용**이다. 같은 시설에
  고마하 동반 시험이 존재할 수 없다.
- TR 1096 자신의 참조 9건 전수 확인 — 전부 저속. 고마하 0건.
- 각주의 대체 대상(TN 2381·2382)도 저속.
- 이 모델 계열 17건의 **풍동** 항목이 전부 같은 저속 시설이다.
- 마하가 높은 두 건은 풍동이 아니라 자유낙하·로켓 비행시험이고,
  전자는 *"lift coefficients up to 0.26"* 이라 받음각 범위로 쓸 수 없다.

### TR 1096 은 "다른 기체의 표" 가 아니다

**시험·인터페이스 검증용 기준 형상 자신의** 표다 — 실제 기체 형상으로
확정한 것이 아니라, 배관과 계약을 검증할 대상이다. Table I 대조:
`b/MAC = 36/9.19 = 3.917` 이 우리 `2.000000/0.510556 = 3.917` 과 일치하고,
동체 F2 세장비 6.67, 꼬리 용적 `0.20 × 1.8172 = 0.3634`, 모멘트 기준
0.25 MAC 이 모두 일치한다.

반대로 다른 후보를 쓰면 문자 그대로 다른 비행체를 계산한다. 특히 비선형
`Cm(α)` 가 그 차이에 가장 민감하다 — TR 1096 자신의 결론이
*"the longitudinal stability characteristics were impaired ... by moving the
horizontal tail upward"* 이므로 **미익의 후류 대비 수직 위치가 pitch-up 의
지배 인자**인데, 후보들은 바로 그 항목이 다르다.

## 4. 반증 감사가 잡은 오류 3건

전부 주변부이며 위 결론과 개별 (a)~(f) 판정은 그대로 유지된다.
그러나 기록한다 — 잡히지 않았으면 다음 사람이 그대로 인용했을 것이다.

1. **RM L55I23a** — 탐색이 제시한 산출물 파일이 **실재하지 않았고**,
   용어 스캔 "13개 term 0건" 이 **틀렸다**. 실제로는 `fighter` 1건
   (참조 제목). 맥락이 참조 제목이라 중립성 판정 자체는 살아남지만
   보고된 개수가 틀렸고 재현되지 않았다. 그 문서의 실제 α 범위
   (*"about −2° through 24°"*)도 보고되지 않았다.
2. **TR R-428 의 `missile` 1건** — "참고문헌 제목" 이라 했으나 실제로는
   **본문 서론**의 동기 문장이다. 탐색이 TR R-474 에는 올바로 적용한
   맥락 구분을 여기서 빠뜨렸다.
3. **Multhopp 사용 범위** — "`Kp` 하나뿐" 이라 했으나 원문은
   *"The constant **Ki** can be determined from any reliable lifting-surface
   theory, and the modified Multhopp theory described earlier will be used"*
   로 `Ki` 도 같은 이론에서 구한다. 더 큰 결론(부착유동 선형 이론)은 유지.

## 5. 현재 상태

> **코드 실패가 아니라 공개 물리 근거의 한계에 도달한 상태다.**

| 계수 | 상태 |
|---|---|
| `CL_α(M)` | TN 3911 관계 회수·검산 완료, **미연결** (출처는 유효 받음각 범위를 주지 않음) |
| 비선형 `CL(α,M)` · `CL_max(M)` | **UNKNOWN** |
| `Cm(α,M)` | **UNKNOWN** |
| `Cm_q` (대역 내) | **UNKNOWN** (폐쇄 실패 기록 — `v0_aero.hpp`) |
| 물리적 성립성 | **UNKNOWN** — 가능·불가능 어느 쪽도 판정하지 않음 |

요구조건 역산(`requirements_sweep`)은 A·B 로 완료했다. 문헌 탐색과 계수
추측은 **여기서 중단**한다.

다음은 CFD 자체가 아니라 **산업체 6DOF 데이터 공급 계약과 검증 절차**를
확정하는 것이다(`SUPPLIER_DATA_CONTRACT.md`). 그 계약이 완성되면:

- 산업체가 데이터를 입력하면 실제 모델 판정 진행
- 제공이 늦으면 CFD·별도 시험을 독립 마일스톤으로 수행
- 둘 다 없으면 물리적 성립성은 계속 UNKNOWN
