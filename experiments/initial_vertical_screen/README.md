# 초기 수직 자세전환 — 점질량 선별 (비생산)

ADR-0003 §3의 표를 만드는 독립 실험. `COLCON_IGNORE`로 빌드에서 제외돼
있으며 **생산 코드가 아니다.**

## 무엇을 하는가

속도 벡터가 정확히 수직이고 속력이 0보다 큰 상태에서 출발해, 비행경로각을
목표까지 일정한 변화율로 내린다. 그 동안 선회에 필요한 양력계수가 CLmax
안에 있는지, 속력이 순항 하한 위에 남는지를 본다.

## 무엇을 하지 않는가

모멘트·관성·제어 권한·액추에이터 상태를 **하나도 보지 않는다.**

- **배제된 사례는 진짜로 배제된다** — 생략한 효과는 전부 요구를 어렵게
  만들지 쉽게 만들지 않는다
- **배제되지 않은 사례는 가능성이 증명된 것이 아니다** — 배제에 실패한 것뿐

결과 칸을 그대로 읽어야 한다. "통과"라고 읽으면 안 된다.

## 방정식·가정

`screen.py` 머리글이 한 곳에서 정의한다 — 운동방정식, 중력·대기·항력·추력
방향 가정, 적분법, 지배 변수군 유도. 문서와 코드가 갈라지지 않도록 여기서
반복하지 않는다.

지배 변수군만 옮겨 적으면:

```
CL_req = (2 (m/S) / ρ) · ( γ̇ / V  +  g cos γ / V² )
```

면적하중 m/S, 밀도 ρ, 순간 속력 V, 자세 변화율 γ̇, 중력 투영 cos γ.

## 실행

```bash
python3 screen.py            # ADR-0003 §3의 표 A·B 재생성 + dt 수렴 출력
python3 screen.py --check    # dt 0.02–0.001에서 판정 불변 (어긋나면 종료코드 1)
python3 screen.py --verify-doc ../../docs/adr/0003-initial-vertical-6dof.md
                             # 문서에 적힌 표가 이 실행과 같은지 (어긋나면 1)
```

`--verify-doc`가 있는 이유: 문서의 숫자가 코드와 갈라지면 그 절은 측정이
아니라 계산 메모다. 갈라지면 조용히 넘어가지 않고 실패한다.

## 한계

- 점질량. 6DOF 판정을 대신하지 않는다
- 밀도 일정 — 짧은 구간의 저고도 근사
- 뱅크 0 — 평면 내 기동만
- 명시적 오일러 적분 — dt 수렴을 매 실행 확인하는 이유

표 B(면적하중 민감도)는 **설계안이 아니다.** S만 바꾸고 스팬·시위·관성·
모멘트 계수를 그대로 두므로 각 행은 일관된 하나의 비행체가 아니다.
