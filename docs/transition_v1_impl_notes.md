# 전이 생성기 v1 — 구현 결정과 유보 항목

프로젝트 정의 중립 3DOF 벤치마크 모델(공개 운동방정식 + 명시적 가정
파라미터) 기반 알고리즘·연결 구조 검증이며, 실제 플랫폼 물리 검증이
아니다.

## 1. 결정한 열린 질문

- 모델 상한 초과 시작 상태: UNSUPPORTED. 모델이 정의되지 않는 영역에서
  전이를 주장하면 물리 주장이 된다 — v1 금지.
- 초기 가속도: 메시지 계약의 `use_initial_acceleration` bool을
  FSM→plan()→코디네이터→TransitionRequest까지 그대로 전달 — 처방
  여부는 **bool이 결정하고 수치는 결코 결정하지 않는다**(수치 0
  센티널은 "정확히 0을 처방"을 표현 못 함; 검토 지적). 처방 시: 부호
  보존 역산(`invertPointMassCommands`, 윈드 삼축 atan2 — 공용 역산의
  acos는 선회 방향을 잃는다)으로 u0를 구해 EOM으로 재평가, 명령 가속
  재현(1e-5 이내)일 때만 수용하고 첫 4 s 명령 공간 램프로 정확히
  보존한다(측정 재현 오차 4e-16). 미처방 시: 모델 유도 시작 가속 사용,
  `start_acc_model_mps2`로 보고. 날 수 없는 처방(50 g, 급상승 중 정확
  0)은 거부 — 세탁 불가(회귀 gate_startacc·acc_prescribed_zero·통합
  racc/rz). 다항 브리지 방식은 기각: 풀스로틀 기록을 따라잡으려 어떤
  브리지 길이에서도 추력 상한을 넘는다(측정 3.21 kN > 3.2 kN).
- dwell 1.0 s, 포획 횡회랑 10 m, t_go 창 [1.5 s, 0.85 × blend_t_max]:
  실험적 초기값. 수용 보정값 아님. 근거는 코드 주석에 있고, 변경은
  결정성 회귀(`determinism`)와 실현성 스파이크(`feasibility`)를 다시
  통과해야 한다.
- FSM 중복 삭제(설계 문서 항목): 실제 구조 확인 결과 중복이 아니었다.
  FSM의 인벨로프 게이트는 비체인 단일 경로 전용이고 체인 경로는
  `plan()` 내부 검증에 위임한다 — 삭제하면 비체인 경로가 fail-open.
  변경하지 않았다.

## 2. 조종 법칙(고정 프리미티브)의 구조적 사실

- γ 명령은 모델 자체 권한으로 구속: 하강 = 제로 양력 푸시오버의 95%
  (음수 CL 도달 불가 — cl_lo = max(0, cl_min)), 상승 = CL 헤드룸의
  80%. 상승 헤드룸이 음수면 실속 — 정직 실격.
- 추력은 고도별 실속 하한(1.1 × stall(z)) 기준 에너지 관리. 얕은
  강하의 요구 추력이 idle 미만이면 idle로 비행(법칙의 결정) — 속도
  창 게이트가 결과를 판정한다.
- 조준은 진입 **선**(접선) 위 4 s 선행점. 점 자체를 쫓으면 횡편차가
  t_go에 비례해 포획 창이 열릴 때 회랑 밖이다(측정: 600 m 수직
  오프셋이 t_go 0.4 s에야 10 m 미만).
- 명령 내부 마진 규율: 한계의 0.1% 이내 요구는 EOM 클램프 전에
  실격. 수용된 후보는 전 구간 엄격한 내부 마진을 증명하고, EOM의
  포화 플래그는 구현 드리프트 감지기로만 남는다.
- RK4 4단계 모두에서 힘 재평가(representable = AND, saturated = OR).
  상태 클램프 없음 — 이탈은 게이트가 잡는다.
- 스텝별 전환 한계 게이트(`disq_limits`): 속도 대역
  [activation, speed_max]·동압·하중계수 — 포화 플래그가 못 보는
  한계를 같은 Parameters로 매 스텝 판정. 경사각 범위만 §8 미확정으로
  프리가드 콘 유지.
- 완성 다항 궤적 전량 재검증(`validateTransitionTrajectory`, 공개
  API): 실제 비행하는 것은 RK4 표본이 아니라 다항식이다. 전 구간
  유한성·지형 AGL·존 정책·속도 대역·동압 + **전 구간 역동역학**
  (하중·CL·추력·뱅크·표현 가능성; 순항 경사 콘만 §8 미확정으로 제외),
  표본 간격 = min(dt, 호 2 m), 얇은 여유는 국소 dt/16 세분.
  **여유(slack) 없음**: 다항식이 실행 궤적이므로 적합 오차는 물리
  한계를 넓힐 근거가 아니다(검토 지적 — 이전 slack 모델은 무차원
  하중 여유를 rad 뱅크 한계에 더하는 차원 오류까지 있었다). 적합
  오차는 어댑터 품질 게이트 전용이고, 맨 한계에서 실패하면 매듭 표본
  수 절반의 사다리(정수 시프트라 실제 0.50→0.24→0.12 s, 오차
  ~16×/단 감소)로 재표현, 전부 실패 시 후보 거부. 이 과정에서 법칙의 idle 명령이 정확히
  thrust_min 경계에 올라타 적합 노이즈(~2 N)가 하한을 넘던 결함 발견
  — idle에도 상한과 대칭인 2% 마진(`kIdleMarginFrac`). 음성 회귀:
  지형 침하 + **내부 추력/하중 초과**(t³(Tm−t)² 가속 융기 — 끝점
  위치·속도 불변, 내부만 침범) 모두 거부 고정; 정상 승자의 zero-slack
  통과도 고정. 승자 노출 통계는 최종 다항식 위에서(`risk_*`), 탐색
  전체는 별도(`search_risk_*`).
- 분류기와 미처방 가속: `classifyStartState(..., acc_prescribed)` —
  미처방 내부값(FSM의 0)은 분류 근거가 아니다(속도 상태만 판정:
  `stateEnvelopeProblem`). 처방 시에만 전체 PVA 판정. 회귀: 같은
  위치·속도(콘 안 25° 상승)에서 미처방 0 = CRUISE_VALID, 처방 0 ≠
  CRUISE_VALID(유지 불가 추력).
- 라이브 스모크 시나리오 분리: `r5_transition_reject_probe.yaml`(처방
  [3,0,2] = 추력 116% — 세탁 금지 확인용 거부 스모크),
  `r5_transition_success_probe.yaml`(가속 미처방 — 전체 연결 성공
  확인용; 처방 성공 실험은 −4·v̂ = [0, 3.392, −2.120] 참고).
- 인계 속도 상한은 한 곳에서 정의: `effectiveHandoffMaxMps()`
  (명시 캡 → 계획 캡 → 모델 상한). 생성기·판정기가 같은 값을 읽어
  회복 가능한 입력이 캡 불일치로 낭비 실패하지 않는다.

## 2.5 라이브 스모크가 찾은 조종 법칙 불연속 (2026-08-08)

실지형(r5)에서 성공 스모크가 처음에 실패한 원인은 게이트가 아니라
법칙의 **명령 불연속**이었다 — 기록의 가속 점프는 다항식이 어떤 매듭
밀도로도 못 따르며(측정: 매듭 3단 사다리에서 적합 가속 오차가
4.9→3.9→4.1 m/s²로 불변), zero-slack 검증기의 거부가 옳았다. 세 곳을
연속화:

- 추력: v_lo/v_hi 하드 분기 → 홀드(항력+중력 보상) + 비례 속도
  서보(400 N/(m/s)), [t_lo, t_hi] 클램프.
- γ 기준: t_go=30 s에서 램프→LOS 하드 스위칭이 한 스텝에 레벨→풀
  푸시오버(측정 8.6 m/s², acc_z −9.26)를 만들던 것 → 5 s 창
  크로스페이드(w는 상태 연속).
- 뱅크: capture_align 데드밴드 컷오프 제거(비례 법칙이 오차와 함께
  자연 소멸).

수정 후 기록 최악 점프 0.34 m/s², 적합 오차 0.25, 검증기 bare-limit
통과. 교훈: zero-slack 검증기는 게이트가 아니라 **법칙 품질의
검출기**로도 작동한다 — 완화했다면 불연속 명령이 실기로 나갔다.

## 3. 측정된 수치(회귀로 고정)

- 개루프 RK4 수렴 기울기 3.997–3.999 (O(dt⁴)).
- 폐루프(스텝마다 명령 재계산) 유효 차수 ≈ 1.0 — dt 예산은 실제
  적분되는 이 계 기준으로 정당화한다. dt=0.02 s에서 종단 오차는 측정
  격자 최소점보다 훨씬 아래.
- 역동역학 왕복 오차: 추력 1e-12 N, 뱅크 1e-15 rad 수준.
- γ=32° 수용 시나리오: 165 m/s 회복(포획 t_go 5.1 s, 횡 9.7 m, 전이
  33.0 s), 125 m/s는 실속 게이트로 거부. 140 m/s는 점-추적 구법칙에서
  거부되었으나 선-추적은 정직 회복 — 경계 이동은 감사 카운터로 추적.
- 라이브 스모크 (r5, 2026-08-08, transition/enable=true): 성공 —
  winner 9, dwell 31.9 s, 적합 p/v/a 0.001/0.011/0.25, 접합 dP 9e-13 /
  dV·dA 2e-16 u, 선행 TRANSITION 37.4 s 포함 전체 1114.7 s 343조각,
  FINAL-EVAL CLEAN, start_acc_model 3.94 m/s² 보고. 거부 — 처방
  [3,0,2](추력 116%)가 열거 0에서 "not flyable by the model"로 거부,
  무궤적·무폴백·시퀀스 롤백. 중립 벤치마크 시뮬레이션 검증이며 실제
  플랫폼 물리 적합성 승인이 아니다.

## 4. v1 유보 목록 (v1-DEFERRED)

- 프리미티브 배열의 설정화(param-array config): 컴파일 상수 유지.
- STALE 시 경로 재커밋 1회 재시도(recommit-on-stale): 코디네이터는
  현재 즉시 FAILED.
- 노출 최소화·후보 순위: 테이퍼 일치 비용 API가 그 비용 설계와 함께
  생기기 전 금지(`zoneExposureRaw`는 통계 전용).
- §8 접합 jerk 상한: 매 실행 측정·기록만. 분포가 쌓이면 §8에서 확정.
- 시작 접합 가속도 게이트: 모델 한계로 측정만.

## 5. 진단 모드

- `TP_DEBUG=1`: 실격 지점 상태 덤프(실속·포화·블렌드 인벨로프).
- `TP_TRACE=1`: 후보별 진행 상태(250스텝 간격)와 종료 사유.
- 코디네이터는 매 실행 감사 요약을 로그로 남긴다(열거 수, 승자 id,
  게이트별 실격 카운터, dwell, 노출 통계, 어댑터 오차, 시작 접합
  점프).
