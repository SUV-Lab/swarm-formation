# ADR-0001: 첫 참조 모델 선택안 (기각 — ADR-0002로 대체)

- 상태: **기각** (2026-08-07 리뷰). 유지된 것은 "공개 자원 기반 참조 모델
  하나를 개발 스펙으로 쓴다"는 방침뿐이며, 이 문서가 시도한 특정 모델
  선택과 수치 동결은 승인되지 않았다. 대체: `0002-neutral-benchmark.md`.
- 이력 정정: 초판은 "사용자·코덱스 합의"로 기재했으나, 합의된 것은 공개
  자원 사용 방침까지였고 특정 모델 선택은 합의된 바 없다 — 작성자의
  월권이었다.
- 초판 원문(선택했던 모델의 명칭·수치·추출 근거 전문)은 git 이력
  `cc27894`에 있다. 군사 플랫폼 명칭을 현재 트리에 두지 않는 저장소
  방침에 따라 본문에서 제거했다. 추출 방법론(XML 추출, 극선 적합, 부분
  집합 검산, 운용/물리 분류)은 모델 중립적이므로 필요 시 그 커밋을
  참조한다.

## 기각 사유 (요지)

1. **단계 의미 불일치**: 원래 문제는 발진 직후 상태 → 순항 인계인데,
   선택했던 모델은 활주로 운용 고정익이라 연구 대상이 "비정상 비행 상태
   → 순항 복귀"로 바뀐다.
2. **군사용어 제거 방침 충돌**: 명시적 군사 플랫폼 명칭·용어가 저장소에
   재유입된다.
3. **라이선스 오기**: 항공기 데이터 파일은 자체 fileheader에 GPL을
   선언하는데 초판은 라이브러리 라이선스(LGPL 2.1)로 기재했다. 데이터
   파일 라이선스는 라이브러리와 별도로 관리한다.
4. **"정합 완료" 과장**: 연료 상태 선택·트림 제외 적합·추력 테이블
   상수화는 동일 기체 정합이 아니라 coarse surrogate다. 회귀 통과는 배관
   회귀일 뿐 물리 일치의 증거가 아니다.
5. **인계 상한 충돌**: 모델 상한(230 m/s)과 MINCO 프레임 상한(max_vel
   200 m/s) 사이 상태가 입구 검증을 통과한 뒤 솔버에서 실패한다. →
   `stateEnvelopeProblem`이 유효 상한 min(모델, 프레임)으로 검사하도록
   수정됐다(회귀 initceiling).
6. **연구 정책 값 조기 동결**: 실험 초깃값을 acceptance contract로
   동결하기엔 이르고, 생성 결과의 분포로 그 결과의 합격선을 정하는 것은
   순환 논리다.

## 남긴 것

- 기본 `optimizer_params.yaml`은 중립 generic baseline으로 복구됐다.
- 재선정 기준(ADR-0002가 충족해야 함): 중립 명명, 데이터 라이선스 명확,
  전이 영역 실제 커버, 전환·순항 동일 물리 비교 가능, 군사용어 방침
  무충돌.
