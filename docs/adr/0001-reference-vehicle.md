# ADR-0001: 공개 참조 기체 채택 — JSBSim F-16A를 계약 2 개발 스펙으로

- 상태: **채택** (2026-08-07)
- 결정 주체: 사용자·코덱스 리뷰 합의, 본 문서로 동결

## 결정

계약 2(TransitionPhase)의 개발 목표를 **실제 플랫폼 인증이 아니라 공개
참조 기체 기반의 기능 구현·연구 실험**으로 확정한다. 이에 따라 외부
플랫폼 스펙을 기다리지 않고, 아래 공개 모델을 reference vehicle로
동결하여 계약 문서 §8(한계 수치)·§11(전환 모델)의 스펙 역할을 하게 한다.

| 항목 | 값 |
|---|---|
| 모델 | JSBSim 번들 `aircraft/f16/f16.xml` — "General Dynamics F-16A Block-32 (Basic US configuration)" |
| 엔진 | `engine/F100-PW-229.xml` (milthrust 17,800 lbf / max 29,000 lbf, Aero-Matic 생성) |
| 버전 고정 | JSBSim **v1.3.1 @ `3b25f25e49b42d0489c04ac805674fc1450ca579`** (experiments/jsbsim_probe/run.sh가 SHA 대조) |
| 라이선스 | LGPL 2.1 (JSBSim COPYING) |
| 데이터 출처 | NASA TP-1538 풍동 데이터(1979), Caltech Murray 모델, NASA H-1999/H-2177 등 — 모델 헤더 명시 |

**범위 선언 (필수 표기)**: JSBSim 프로젝트는 번들 기체를 "공개 자료로 만든
근사 모델이며 교육·오락 용도"라고 명시한다(README), 모델 자체도 "실제
제조사와 무관, as-is 제공"을 선언한다. 따라서 본 참조 기체 기반의 모든
결과는 **공개 참조 모델 기반 구조·알고리즘 검증**으로만 표기하며, 실제
플랫폼 적합성은 주장하지 않는다.

## 선정 근거

- 번들 기체 중 아(亞)음속 저고도 122–230 m/s 순항 + 2.5 g 지속선회 + 30°
  상승을 모두 여유 있게 커버하는 가장 완전한 모델(공력 테이블·FBW FCS·
  터보팬 추진 전부 데이터 파일로 존재).
- 지금까지의 프로브 측정(순전파 비용·PVA 추출·Hermite 재표현)이 전부 이
  모델로 이뤄져 연속성이 있다.

## 동결된 기체 물리 (전환·순항 공용)

f16.xml에서 직접 추출/적합(fit)한 값. 산출 근거는 각 행에.

| 항목 | 값 | 근거 |
|---|---|---|
| 질량 `mass_kg` | **9357.6 kg** | empty 7892.5 + 조종사 104.3 + 기본 탑재 연료 1360.8 (파일 기본 로드아웃, **선택값** — 아래 주의) |
| 날개 면적 `wing_area_m2` | **27.871 m²** | f16.xml:37 (300 ft²) |
| `zero_lift_drag_coefficient` | **0.017** | CLDh/CDdHT elevator=0 열의 순항 영역(α 0–15°) 최소자승 적합, 잔차 RMS 0.002 |
| `induced_drag_factor` | **0.152** | 같은 적합 (CD = 0.017 + 0.152·CL²) |
| `lift_coefficient_max` | **1.829** | f16.xml CLDh, α=35°에서 (저마하 — 테이블에 마하 의존 없음) |
| `thrust_min_n` | **0.0** | idle이 영역 대부분에서 ≤0 (M0.4 해수면 코너 +372 N은 최소 항력의 4%, 무시 가능으로 기록) |
| `thrust_max_n` | **61,000 N** | 영역 내(0–2 km, 122–230 m/s) MIL 추력의 **최솟값**(2 km·M0.37에서 61.1 kN) — 테이블 값(61.1–77.4 kN)의 보수적 상수화. AB는 쓰지 않는다 |

**주의(가정 플래그)**: 질량은 파일이 정한 기본 로드아웃(내부연료 43%)이지
설계 총중량 추출이 아니다. 적합은 elevator=0(트림 항력 미포함), Tmax는
마하·고도 테이블의 보수적 상수화다.

## 운용 한계는 미션 정책으로 유지 — 부분집합 검산 완료

기존 순항 운용 한계는 참조 기체 능력의 **엄격한 부분집합**임을 수치로
확인했으므로 그대로 둔다:

| 운용 한계 | 부분집합 검산 |
|---|---|
| 속력 122–230 m/s | 실속 54.2 m/s의 2.25배 위; 230 m/s = M0.68 < 0.81 (파동항력 0) |
| n ≤ 2.5 g | 공력 한계 5.06 g(최악 코너), FCS 구조 한계 9 g; 2.5 g 지속선회 항력 ≤ MIL의 50% |
| γ ≤ ±30° | 상승 추력 여유 확인. 단 **230 m/s·2 km 코너에서 59.6 kN vs 동결 Tmax 61 kN로 빠듯** — 콘은 밴드 상단에서 추력 제한임을 기록 |
| 동압 ≤ 45 kPa | 230 m/s 해수면에서 32.4 kPa |

정속 순항 추력 요구는 전 밴드에서 MIL의 13–18% — AB 불필요.

## 제어 입력 범위 (전이 생성기의 u(t) 공간)

| 입력 | 명령 범위 | 실면 범위 | 비고 |
|---|---|---|---|
| `fcs/throttle-cmd-norm` | [0, 1] | — | MIL까지만 사용(AB 금지, 위 Tmax 상수와 일관) |
| `fcs/elevator-cmd-norm` | [−1, +0.44] (FCS 클립) | ±0.436 rad | 9g/−4g 제한 구현, 액추에이터 풀트래블 0.3 s |
| `fcs/aileron-cmd-norm` | [−1, 1] | ±0.375 rad | 마하 게인 스케줄 존재 |
| `fcs/rudder-cmd-norm` | [−1, 1] | ±0.524 rad | 0.4 s |

**중요**: 이 FCS는 rate/G-command FBW라 cmd-norm이 실면 위치에 비례하지
않는다(`fcs/fbw-override`=1이 아닌 한). 전이 생성기는 명령 공간에서
탐색하고, 상태 판정은 출력 PVA로 한다.

## 순항 모델(mmp_vehicle_dynamics) 파라미터 정합

분류(코드 조사로 확정): VEHICLE PHYSICS는 참조 기체 값으로 교체, 환경
상수는 유지, 운용 한계는 미션 정책 유지, 수치 안정 항목은 재검토.

| yaml 키 | 현재 | → 동결값 |
|---|---|---|
| dynamics_mass_kg | 1300.0 | 9357.6 |
| dynamics_wing_area_m2 | 1.0 | 27.871 |
| dynamics_cd0 | 0.035 | 0.017 |
| dynamics_induced_drag_factor | 0.080 | 0.152 |
| dynamics_cl_max | 1.40 | 1.829 |
| dynamics_thrust_max_n | 3200.0 | 61000.0 |
| (speed_min/max, load_factor_max, flight_path_max, q_max, bank_max) | — | **유지** (운용 정책, 부분집합 검산 완료) |

파급 효과: 기존 순항 수치로 튜닝된 감사·회귀가 이 교체로 이동한다. 특히
기존 모델에서 122 m/s 플로어는 실속(121.9 m/s)의 사실상 등가였지만, 참조
기체에서는 실속이 54.2 m/s라 **플로어가 순수 미션 정책이 된다**. 교체는
회귀 전수 재실행과 함께 별도 커밋으로 수행한다.

## 전환→순항 겹침 영역과 완료 조건 (연구 정책 v0)

계약 문서 §8의 자리에 들어갈 초기값. **연구 정책이며 실험으로 조정한다**
— 실제 플랫폼 값 주장이 아니다.

| §8 항목 | v0 값 | 근거 |
|---|---|---|
| 전환 허용 속력 | 60–275 m/s | 하한 = 실속 54.2 + 여유, 상한 = M0.81(파동항력 0 영역) |
| 전환 허용 상승각 | ±60° | 연구 초기값 (JSBSim 모델은 준수직도 전개 가능; FCS 9g 내) |
| 전환 하중 | ≤ 4.0 g | 연구 초기값 (FCS 한계 9 g의 부분집합) |
| 접합 jerk 점프 상한 | 1단계 구현에서 **측정 분포로 설정** | Hermite 실험 실측: 명령 계단에서 ~35 m/s³ |
| 전이 완료(겹침 영역 체류) | 속력 [132, 230] ∧ \|γ\| ≤ 30° ∧ `pvaEnvelopeProblem()` 통과 ∧ 경로 접선 정렬 ≤ 10° ∧ 체류 ≥ 1.0 s | 진입 플로어 132 = margin-backed(계약 §9), 체류 1.0 s는 프로브에서 사용한 값 |

## 결과

1. 계약 2는 더 이상 외부 스펙 대기가 아니다 — 이 ADR이 §8·§11의 스펙이다.
2. 착수 순서: **① 순항 파라미터 교체 + 회귀 전수 재실행(위 표)** →
   ② 계약 §13의 선행 정리(commitRoute 분리 등) → ③ 1단계 구현(무최적화
   전이 생성 → 다항화 → 검증 → C² 연결).
3. 모든 산출물 표기: "공개 참조 모델(JSBSim F-16A) 기반 구조 검증".
