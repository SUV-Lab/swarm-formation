# ADR-0003: 초기 수직 자세전환 구간의 6DOF 모델 (v2 초안)

- 상태: **초안 v2 — 승인 전. 생산 코드 구현 착수 금지.**
- 제안 2026-08-14, v2 2026-08-15. 브랜치 `lgh/initial-vertical-6dof`.
- v1 검토 결과 **방향 조건부 승인 / 문서는 보완 후 재승인**. v1의 사실관계
  오류 4건은 §10에 정정 이력으로 남긴다.
- 관계: ADR-0002를 **대체하지 않는다.** 중기 순항은 3DOF 중립 벤치마크를
  그대로 쓴다. ADR-0002가 스스로 예고한 확장이다 — *"준수직 발진이
  요구되면 모델 확장이 필요하며 가드가 조용히 흡수하게 두지 않는다."*
- ADR-0001의 기각 사유 6개 대조는 §8.

## 0. 범위 선언 (모든 산출물 필수 표기)

> **공개 참조 모델 기반 구조 검증**이며, 실제 플랫폼 물리 검증이 아니다.
> 특정 업체·플랫폼의 성능을 주장하지 않는다.

명시적 제외: 특정 플랫폼 성능 추정, 표적 관련 기능, 제한 도메인 고유명사.

## 1. 두 모델의 역할 — 먼저 못 박는다

v1이 흐렸던 부분이다. 검토 지적에 따라 명시한다.

| 모델 | 역할 | 쓰이는 곳 |
|---|---|---|
| **3DOF 점질량** (`point_mass_eom.hpp`) | **계획용 근사 모델** | 중기 순항 계획, MINCO 비용 항 |
| **6DOF** (신규) | **실행 가능성 평가 모델** | 초기 수직 자세전환 구간의 생성·판정 |

6DOF는 3DOF를 대체하지 않는다. **계획은 근사 모델이 하고, 그 결과가
실제로 날 수 있는지는 평가 모델이 본다.**

---

## 2. 문제 정의 — 요구조건을 먼저 나눈다

```
수직 초기 상태  →  자세를 점진적으로 기울임  →  중기 경로 정렬
```

요구하지 않는 것: 수직을 넘어가는 루프. 상승각은 90°에서 단조 감소만 한다.

### 2-1. 두 경우를 구분해야 한다 — v1은 섞었다

| 경우 | 초기 상태 | 추진 요구 |
|---|---|---|
| **(A) 정지 수직 발진** | 속도 0 | **T/W > 1 필수.** 아니면 뜨지 않는다 |
| **(B) 수직 속도 보유** | 이미 상방 속도 | **T/W ≤ 1도 성립.** 감속을 허용하며 자세를 바꾼다 |

요청 문면은 *"정확히 수직인 초기 상태"* — **상태**이지 정지가 아니다.
따라서 기본은 **(B)**로 본다. (A)를 요구하는지 확인이 필요하다(§9-1).

### 2-2. 현행 3DOF로 불가능한 이유 (측정치)

| 벽 | 값 | 성격 |
|---|---|---|
| 기동 조각 목록 | 최대 +20° | 코드 상수 `kGammaTargetsRad` |
| 모델 상승각 상한 | 30° | 설정 `dynamics_flight_path_max_deg` |
| 초기 구간 허용 상한 | 80.21° | 코드 상수 `max_abs_gamma_rad{1.40}` |
| **수식 한계** | **87.13°** | `acos(kMinCosGamma)` |

앞의 셋은 값이다. 마지막만 형식 문제다: 방위각 변화율이 `… / cos(상승각)`
이라 수직에서 0으로 나눈다. 지구본의 극점에 경도가 없는 것과 같아 값을
낮춰 피할 수 없다. 같은 물리 기동(초당 1° 기울임)이 89.9°에서는 한 적분
단계(0.05 s)에 방위각을 **28.6°** 움직인다.

**결론: 각도 좌표를 확장하지 않는다.** 위치·속도벡터·쿼터니언·각속도·질량을
상태로 갖는 별도 모델을 쓴다.

## 3. 1차 타당성 선별 — 추진 수치를 정하기 전에 할 수 있는 것

v1은 *"추진 스펙을 프로젝트가 선언해야 진행 불가"*로 끝냈다. **그 결론은
틀렸다.** 무차원 관점으로 보면 무엇이 실제로 결정하는지가 먼저 나온다.

경우 (B), ADR-0002 중립 baseline(1300 kg, S=1 m², CD0 0.035, k 0.080,
CLmax 1.40), 자세 전환 90°→20°, 저고도 밀도 근사, 단순 적분:

| 초기속도 | T/W | 램프율 | 소요 | 종료속도 | 필요 &#124;CL&#124;max | 판정 |
|---|---|---|---|---|---|---|
| 190 | 0.25 | 8.6°/s | 8.1 s | 123.9 | 2.08 | CL 초과 |
| 190 | 0.25 | 4.0°/s | — | — | 1.00 | 속도하한 미달 |
| 190 | 1.00 | 4.0°/s | 17.5 s | 213.8 | 1.00 | **통과** |
| 230 | 0.25 | 4.0°/s | 17.5 s | 128.0 | 0.80 | **통과** |
| 230 | 1.00 | 4.0°/s | 17.5 s | 248.8 | 0.80 | **통과** |

**T/W = 0.25에서도 통과하는 조합이 있다.** 추진 증강이 전제가 아니다.

무엇이 실제로 결정하는가 — 날개면적 스윕 (T/W = 0.25 고정, 램프 8.6°/s):

| S (m²) | 초기속도 | 필요 &#124;CL&#124;max | 판정 |
|---|---|---|---|
| **1.0** | 190 / 230 | 2.08 / 1.72 | CL 초과 / CL 초과 |
| 2.0 | 190 / 230 | 1.03 / 0.85 | 통과 / 통과 |
| 4.0 | 190 / 230 | 0.51 / 0.43 | 통과 / 통과 |

**결정 요인은 추력이 아니라 (초기속도 × 램프율 × 날개면적)이다.**
그리고 ADR-0002의 `S = 1 m²`는 명백한 자리표시자로, 이 선별을 지배하고
있다. 즉 v1이 "추진 스펙"을 물었어야 할 자리에서 실제로 물었어야 할 것은
**기준 면적과 허용 자세 변화율**이다.

한계 명시: 이 선별은 점질량 근사이며 모멘트·관성·제어 권한을 보지 않는다.
**가능성을 배제하는 데는 쓸 수 있고, 가능성을 주장하는 데는 쓸 수 없다.**

## 4. 공개 참조 모델 조사

검토 지적의 핵심 — *"공개 기준 모델을 쓰자는 요청이 우리가 수치를 정하는
합성 모델로 바뀌었다"*. 먼저 후보를 비교한다.

### 4-1. 후보 비교표

| 후보 | 질량·관성·CG | 형상 | 추력 이력 | 공력 힘/모멘트 | 적용 영역 | 라이선스 |
|---|---|---|---|---|---|---|
| **NASA 공개 리프팅바디 아음속 공력 모델** (TM-4302 계열) | 보고서에 질량 특성 포함 | 공개 | ✗ (무동력 활공 전제) | ✓ 6DOF 다항식 계수 | 아음속 중심. **수직 상승 구간 아님** | 미국 정부 저작물 → 공개 도메인 추정. **확인 필요** |
| **NASA 공개 수송기 시뮬레이션** (Software Catalog 등재) | ✓ | ✓ | ✓ | ✓ 전 영역 풍동 기반 | 수송기 순항 영역. **수직 없음** | 카탈로그 배포 조건 별도. **확인 필요** |
| **AIAA 공개 공력 벤치마크** (원통동체+4핀, 준경험+RANS) | ✗ | ✓ | ✗ | ✓ 힘·모멘트 공개 | **Mach 0.65–4.0.** 저동압 수직 초기 구간 미포함 | 공개 데이터셋. **확인 필요** |
| 시뮬레이터 번들 기체군 | 일부 ✓ (관성텐서·CG 실재 확인) | ✓ | ✓ | ✓ 테이블 | 대부분 활주로 운용 아음속 | **§4-2 참조 — 대부분 미선언** |
| **프로젝트 정의 중립 모델** (자체 형상 + 공개 추정식) | 선언 | 선언 | 선언 | 추정 | 우리가 정함 | 문제 없음 |

### 4-2. 번들 데이터 라이선스 — 전수 재조사

v1은 *"번들 12종 전부 GPL"*이라 썼다. **표본이 12개였고 전체가 아니었다.**
전수로 다시 셌다(로컬 트리 `logs/jsb131`, 기체 디렉터리 61개):

| 선언 | 건수 |
|---|---|
| GPL 계열 (`GPL` / `GPL v2+` / `GPL (General Public License)`) | **14** |
| **선언 없음** | **46** |
| 정의 파일 없음 | 1 |

**과반이 라이선스를 선언하지 않는다.** 이는 GPL보다 재사용에 더 나쁘다 —
조건이 명시된 것이 아니라 불명확한 것이다. 그리고 기존 프로브가 실제로
사용한 모델도 이 46개에 속한다(관성텐서·CG·공력표는 완비돼 있으나 선언
없음).

### 4-3. 판단 — 아직 결론 내리지 않는다

완전한 후보가 없다는 것은 **현시점 조사 범위에서** 그렇다. 검토 지적대로,
그 확인이 끝나기 전에 자체 모델을 채택하면 안 된다.

- 세 공개 후보 모두 **저동압 수직 초기 구간의 추진·질량·관성까지 완성된
  형태가 아니다** — 조사 범위 내 사실
- 다만 각 후보의 **라이선스·배포 조건이 미확인**이다(§9-3)

따라서 §5의 채택안은 **조건부**다: 미확인 항목이 해소되고도 완전한 공개
후보가 없을 때만 프로젝트 정의 중립 모델을 **구조 검증용으로** 쓴다.

### 4-4. 공개 벤치마크의 용도 — 전체 모델이 아니라 독립 비교

AIAA 공개 공력 벤치마크는 적용 영역(Mach 0.65–4.0)이 자세 전환 후반부와
겹친다. 전체 모델로 쓰지 않고 **겹치는 구간의 독립 비교 자료**로 쓴다:

> 우리 모델이 같은 마하·받음각에서 내놓는 힘·모멘트 계수를 공개 벤치마크
> 값과 비교하고, **차이를 수치로 기록한다.** 일치를 주장하지 않는다 —
> 차이가 얼마인지를 밝히는 것이 목적이다.

저동압 수직 구간에는 겹침이 없으므로 그 구간은 비교 대상이 아니며, 그
사실을 산출물에 표기한다.

## 5. 채택안 (조건부)

### 5-1. 물리 엔진: 라이브러리 링크 + 자체 중립 기체 정의

| 대상 | 라이선스 | 근거 |
|---|---|---|
| 라이브러리 | LGPL 2.1 | `COPYING` 실물 확인 |
| 번들 기체 데이터 | GPL 14 / 미선언 46 | §4-2 전수 |

**LGPL에 대한 정정**: v1은 *"우리 코드에 전염 없음"*이라 단정했다.
**그렇게 쓰면 안 된다.** LGPL 2.1은 동적 링크 시 파생물 조건이 완화될 뿐,
**배포 시 고지 의무·재링크 가능성 보장 등 별도 의무**가 있다. 배포 형태가
정해진 뒤 법무 검토를 거쳐야 한다(§9-4). 현 단계 서술은 *"연구용 로컬
링크는 문제 없어 보이나 배포 의무는 미검토"*가 정확하다.

기체 정의는 자체 작성한다 — 번들 데이터를 쓰지 않으므로 GPL·미선언 문제가
모두 비껴간다. 이는 ADR-0002를 깨끗하게 만든 **"서드파티 데이터 파일 0"**
성질의 유지다.

얻는 것: 검증된 6DOF 적분기(쿼터니언 자세·각속도, 극점 없음), 로켓 추진 및
추진제 소모에 따른 질량 변화, 그리고 §6-1의 이미 완료된 좌표 변환.

### 5-2. 기각한 대안

- **자체 6DOF 적분기 작성** — 데이터 공백은 동일하면서 검증된 적분기를
  직접 만들어야 한다. 라이브러리 링크안이 지배한다.
- **번들 기체 데이터 사용** — ADR-0001이 기각한 경로. 재검토하지 않는다.

### 5-3. 감수하는 비용 — 물리 권위가 둘이 된다

ADR-0002의 강점은 "전환·순항이 같은 공식"이었다. 이 결정은 그것을 잃는다.
완화는 §7의 인계 계약이다. 그리고 ADR-0002가 *"합격 판정자가 아님"*으로
규정한 프로브의 지위가 **신규 구간에 한해 판정자로 바뀐다** — 명시적
승인 대상이며, §1의 역할 구분이 그 근거다.

## 6. 구조

### 6-1. 파이프라인

```
① 6DOF 자세전환 궤적 생성   (수직 초기 상태 → 중기 경로 방향 정렬)
② 안정 영역 진입 판정        (6DOF 전체 상태, 지속시간 포함)
③ 종료 상태 → PVA 투영       (판정 통과 후에만)
④ 기존 중기 궤적과 C² 연결
⑤ 연결된 전체 궤적을 6DOF로 재추종 검증
```

| `transition_phase.cpp` | 진입 후보 열거 → 전파 → 판정 → 어댑터 → 감사 계수. **모양 유지, 적분기만 교체** |

| `segment_chain_planner` | C² 연결, 이음매 연속성 검사 |

| `TransitionAudit` | 게이트별 탈락 집계 |
| `transition_experiment_test` | 결정성·연속성 검사 패턴 |

### 6-3. 신규 작성

중립 기체 정의(형상·질량·관성·공력·추진), 라이브러리 래퍼(결정적 고정
스텝), 자세전환 유도 법칙, 안정 영역 판정기, 6DOF→PVA 투영, 재추종 검증
통과.

### 6-4. 손대지 않는 것

`point_mass_eom.hpp`, MINCO의 `flightEnvelopePenalty`, 그리고
**`mmp/initial-planner-rc1` (동결)**.

## 7. 인계 계약 — PVA만으로 쓰지 않는다

v1은 *"인계 PVA를 양쪽 모델이 판정"*이라 썼다. **부족하다.** 같은 PVA라도
자세·각속도·질량·CG·액추에이터 상태가 다르면 실행 가능성이 달라진다.

**순서를 뒤집는다:**

```
6DOF 종료 상태 전체를 먼저 판정
   자세 · 각속도 · 질량 · CG · 액추에이터 상태 · 제어 여유 · 지속시간
        ↓  (통과한 것만)
   PVA로 투영
        ↓
   중기 모델 유효성 확인 (pvaEnvelopeProblem)
        ↓
   C² 연결
```

**투영은 판정 이후다.** PVA는 인계 매체이지 판정 근거가 아니다.

### 7-1. 안정 영역 판정 지표

| 지표 | 의미 |
|---|---|
| 속력 | 중기 모델 유효 범위 안 |
| 자세 | 목표 상승각 근방, 롤 수평 근방 |
| 각속도 | 충분히 작음 — 과도 응답 종료 |
| 동압 | 제어면이 권한을 갖는 하한 위 |
| 제어 여유 | 편향이 포화에서 떨어져 있음 |
| 질량·CG | 선언 범위 안 |

**전부**가 **연속으로 일정 시간** 유지돼야 한다. 순간 통과는 인정하지
않는다.

임계값은 **실험 초깃값**이다. ADR-0001 기각 사유 6에 따라 이 문서에서
동결하지 않으며, 생성 결과의 분포로 합격선을 정하지 않는다.

## 9. 미해결 — 승인 전 답이 필요한 것

### 9-1. 초기 조건의 정의 (프로젝트 결정)
경우 (A) 정지 수직 발진인가, (B) 수직 속도 보유인가(§2-1). **추진 수치를
묻는 것이 아니라 요구조건을 묻는 것이다.** (B)라면 초기 속도 범위가
필요하고, §3의 선별을 그 범위로 다시 돌린다.

### 9-2. 기준 형상 — 추진보다 먼저다
§3이 보인 대로 결정 요인은 기준 면적과 허용 자세 변화율이다. 필요한 것:
길이·직경·기준 면적·스팬·시위·질량 분포·탱크 위치·CG·관성텐서.
**T/W·연소시간·추진제 비율만으로는 정해지지 않는다.**

접근: 공개 후보(§4-1)에서 형상·관성을 회수할 수 있으면 그것을 쓰고,
불가하면 **무차원 스윕**(면적하중, 추력하중, 자세 변화율, 초기속도)으로
성립 영역을 먼저 그린 뒤 그 안에서 대표값을 선언한다.

### 9-3. 공개 후보의 라이선스·배포 조건
§4-1 세 후보 모두 **미확인**. 정부 저작물 여부, 카탈로그 배포 조건,
데이터셋 이용 약관을 각각 확인해야 §4-3의 조건부 판단이 확정된다.

### 9-4. 라이브러리 배포 의무
LGPL 2.1의 고지·재링크 가능성 의무를 배포 형태(정적/동적, 사내/외부)에
따라 검토해야 한다. **연구용 로컬 링크와 배포는 다른 문제다.**

### 9-5. 준경험 추정 코드의 공개 지위
계수 추정 도구의 배포 조건 미확정. 확정 전까지 대안은 공개 문헌의 교과서
준경험식.

### 9-6. 구성 분리
v1 범위에서 **제외**(승인됨). 분리 시 질량·관성·공력이 불연속으로 바뀌는
문제는 v2 범위 밖.
