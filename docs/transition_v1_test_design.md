# 계약 2 v1 테스트 설계 (ADR-0002 벤치마크 기준)

- 상태: **구현 반영** (2026-08-08). §1의 게이트는 transition_phase v1과
  하니스(transition_experiment_test + 체인 transition/transitionauto
  변형)로 구현·고정됨; §8 수치 확정만 남음.
- 원칙: 검사마다 **무엇을 보증하고 무엇을 보증하지 않는지**를 이름에

  검증(validation)이 아니다.

## 1. 해석해 시험 (analytic) — 전이 생성기의 순전파가 물리 공식을 옳게 푸는가

닫힌 해가 존재하는 세 비행 상태에서 RK4 순전파를 해석해와 비교한다.
허용오차는 적분 오차 예산으로 정하며(아래 수렴 시험과 연동), 공식 유도는
교과서 참조를 명시한다.

| 시험 | 설정 | 해석해 |
|---|---|---|
| 정속 수평 직선 | T = D(V), L = mg, μ = 0 | V·t 등속 직선, γ = 0 유지 |
| 정상 수평 선회 | T = D, L·cosμ = mg, μ 고정 | 반경 R = V²/(g·tanμ), 각속도 ψdot = g·tanμ/V |
| 정속 상승 | T = D + mg·sinγ, L = mg·cosγ, μ = 0 | 경사 γ 고정 직선, V 일정 |

각 시험은 입력을 해석 조건으로 고정하고 N초 순전파 후 상태 오차(위치·
속력·각)를 판정한다.

## 1.5 전이 후보 합격 게이트 (fail-closed, 생성기 구현과 함께)

TRANSITION_REQUIRED 분기를 열기 전에 생성기 자체가 다음을 전부
fail-closed로 판정해야 한다(§13 회귀로 고정):

- 유한성·표현 가능성(`state_representable`)·포화(`saturated()`) — 하나라도
  걸리면 후보 실격 (클램프에 속은 탐색 금지)
- 지형 AGL
- **존 정책 상속**: 유효한 `zonePolicySnapshot`이 전제 — STALE/INVALID
  (존/지형 변경, 이후 검색, 다중 leg, 3-pass 미실행)이면 후보 전체
  실격 또는 경로 재커밋. 하드 유지 존 접촉(`zoneContact`=CONTACT) =
  실격; 전역 3-pass가 불가피로 선택한 소프트 존만 통과
  가능(`zoneExposureRaw`로 노출 **측정** — v1은 통계 전용이며, 노출
  최소화·후보 순위는 테이퍼 일치 비용 API가 그 비용 설계와 함께 생기기
  전에는 금지); risk_max 기록만으로 승인
  금지 — 현행 evaluateFlight의 위험도가 판정이 아니라 통계라는 사실을
  생성기가 메우는 지점이다
- 종료 PVA의 `pvaEnvelopeProblem` 통과 (인계 적합성)
- 다항 내부 검사(극값/적응 세분화)와 C² 접합

## 2. RK4 시간 간격 수렴 (convergence) — 적분 구현의 차수 확인

- 동일 입력 프로파일을 dt ∈ {0.02, 0.01, 0.005, 0.001}로 순전파.
- 종료 상태가 리처드슨 외삽 기준 O(dt⁴)로 수렴하는지 판정(로그-로그
  기울기).
- JSBSim 프로브에서 이미 쓴 방법의 자체 모델 판:
  |d(p)/dt − v|, |d(v)/dt − a|가 dt와 함께 수렴해야 한다(프레임 일관성).

## 3. forward/inverse round-trip (consistency) — 두 구현이 같은 물리를 말하는가

- 순전파 궤적의 각 샘플 PVA를 순항 역동역학
  `evaluateInverseDynamics`에 넣어, 역산된 추력·양력·뱅크가 순전파에
  실제로 인가한 입력과 허용오차 내 일치하는지 확인.
- **이름 그대로 consistency test다**: 같은 `Parameters`·같은 극선 공식을
  쓰므로 일치는 기대값이고, 불일치는 물리 오류가 아니라 **구현 버그**를
  뜻한다. 물리 검증이라 부르지 않는다.
- 경계 근처(한계 대비 ±수 %)는 ADR-0001 기각 사유와 같은 이유로 판정
  불일치를 실패로 삼지 않는다(허용오차/히스테리시스 명시).

## 4. PVA → Hermite 재표현 (representation) — 이미 구축된 검사의 재사용

- jsbsim_probe의 hermite_check 방법론 그대로: knot 일치(1e-13급), 조각 간
  C², 구간 내부 오차의 knot 간격 수렴, jerk는 측정만.
- 소스가 자체 모델 순전파로 바뀌므로 프레임 변환 문제는 없음(처음부터
  미션 ENU에서 적분).

## 5. 독립 민감도 비교 (external, 판정자 아님)

- JSBSim 프로브 하니스(중립 번들 예제 기체)는 유지하되 역할은 **민감도
  비교**다: 같은 초기상태·유사 입력에서 자체 3DOF와 외부 6DOF의 정성적
  경향(감속/상승각 변화 방향, 시간 규모)이 크게 어긋나면 조사 항목이
  된다. **합격/불합격 판정에는 쓰지 않는다** — 다른 기체·다른 충실도라
  수치 일치를 기대할 근거가 없다.

## 6. 회귀 배치

- 1~4는 새 하니스(예: `transition_experiment_test`)의 변형으로 추가하고
  기존 chain 하니스와 같은 PASS/FAIL 출력 규약을 따른다.
- 계약 §10의 회귀 계약(분류 3분기·슬라이스 무중복·겹침 영역 거부)은 §13
  구현과 함께 붙는다 — 이 문서의 1~4가 그 선행 조건이다.

## 명시적으로 하지 않는 것

- jerk 상한 판정(§8 스펙 대기 — 자기 분포 순환 금지)
- 실제 플랫폼 물리 타당성 주장
- JSBSim을 합격 게이트로 사용
