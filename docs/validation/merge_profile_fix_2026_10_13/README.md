## 수정 내용

`mergedRetryProfile()`은 원본 phase에서 soft 가중치만 선택한다. 최대속도는 두 원본
worker optimizer에 실제로 구성된 `optimization/max_vel` 중 작은 값을 사용한다.
개별 구간에서 덮어쓴 phase 제한을 다시 적용하지 않으며, 상속된 기본 제한도 명시한
제한과 동일하게 보존한다. 유한·양수가 아닌 worker 제한은 기존 profile 실패 경로로
거부한다.

읽기 전용 `configuredMaxVelocity()`는 optimizer가 보관한 설정값을 반환한다.
manager의 순항 속도나 재시도 시점의 ROS 설정을 대신 읽지 않는다. baseline·단일 계획
fallback·soft 가중치 선택 정책은 유지하며, MINCO/L-BFGS 본체는 변경하지 않았다.
